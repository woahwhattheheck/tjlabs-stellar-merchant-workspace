This directory carries the whole 24-file Class Intake and attendance application. Use an actual POSIX/Python 3.11+ host with Node, Chromium and Playwright already installed. The operator retains the complete public-derived Berea catalogue and explicitly generated administrative examples; the original Sales contact belongs to 48DB and the TONDO/CourseStorm conversation.

The full source carrier expands to 265024 bytes, SHA-256 a955e07603730df76cf73ed824e21f1cddbd4d6f76a487dd66860124e5ee0d39. Every member has its full UTF-8 length and SHA-256. The driver verifies the whole frame and every member before receiving the application. It owns one operation and passes its lock into every child.

~~~sh
python3 -B run-received.py \
  --frame complete-source.json.gz.b64 \
  --sha256 a955e07603730df76cf73ed824e21f1cddbd4d6f76a487dd66860124e5ee0d39 \
  --input /ABSOLUTE/berea-input.json
~~~
