# CoinGecko market workspace

Build a complete market research project, operate a provider-controlled Stellar
data route, and give the customer original sources, readable research and an
editable workspace they can reopen.

The product contains the maintained five-family CoinGecko operator, exact-decimal
source model, browser, merchant MCP provider, managed Applications lifecycle,
native buyer queue, seller and portable recovery. Its selected distribution
keeps those engines and the complete customer workflow together.

## Start work

Use Node 24 or newer and the installed product:

~~~sh
starforge coingecko-product workspace \
  --state /absolute/private/market --port 0
~~~

Open the returned loopback URL. Select or create a project, define requests,
arrange a collection, retain original responses and develop named snapshots,
comparisons and research notes. Supply existing buyer profiles through the
original private operator configuration when native work is needed.

[OPERATING.md](OPERATING.md) follows the complete customer workflow.
[RECEIVING.md](RECEIVING.md) covers selected installation, managed Applications,
customer delivery and interruption recovery.

## Give the customer complete work

Export the named full project archive from Handover, then create the customer
edition:

~~~sh
starforge coingecko-product delivery create \
  --archive /absolute/original-market.json.gz \
  --out /absolute/private/customer-delivery
starforge coingecko-product delivery inspect \
  --directory /absolute/private/customer-delivery
~~~

The directory includes research.html, complete records, every source/comparison
row, exact field CSVs, all original source blobs, the verbatim original archive
and its runnable source closure. delivery.json records every member and hash.
A repeat verifies and returns the original edition.

Receive it into a separate project and continue:

~~~sh
starforge coingecko-product delivery receive \
  --directory /absolute/private/customer-delivery \
  --state /absolute/private/customer-market \
  --actor "Customer operator" --operation original-customer-delivery
starforge coingecko-product workspace \
  --state /absolute/private/customer-market --port 0
~~~

The result identifies the new project. The original model supplies the
transactional restore, ID mapping, source preservation and historical native
jobs. Repeating the same receiving operation preserves that project and its
later customer edits.

Build the committed coingecko selection through the maintained distribution
builder. Its original installer owns the runtime profile and lock. The product
recipe includes the complete browser, Applications/MCP provider, buyer/seller,
source and recovery components.

[COMMERCIAL.md](COMMERCIAL.md) connects the proposed provider implementation,
working sequence, acceptance and source/staging handover. The existing vendor
Base/Solana service and the additional Stellar route retain their own native
terms and settlement identities.
