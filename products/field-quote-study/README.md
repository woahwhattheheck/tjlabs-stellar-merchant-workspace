# Field Quote Study Desk

Open Field_Quote_Study_Desk.html in a modern browser. The ordinary offline operator starts empty and preserves field originals, actual supplied quote editions, pricing rules, source decisions, internal approvals, actual customer delivery and complete work observations.

This is an independent study alongside a field-quoting product. It evaluates supplied records and observed work. It does not generate findings, transcripts, quotes or company approvals and does not publish or send anything.

## Complete first study

1. Define one actual company/team, service scope and consecutive visit window. Retain the full inventory, including unfinished, failed, abstained and withdrawn work.
2. Retain exact field media and notes, actual supplied transcripts, quote payloads, price-book editions and policy records in Supporting originals.
3. Import and map the eighteen canonical CSV families, or enter normal source-backed records through Observed records. Preserve actual device/server receipt identities and times.
4. Review the complete visit population in Visit & measurement plan, including the cutoff, required review roles and all recurring effort phases.
5. Inspect Quotes & delivery study: input availability, price arithmetic, decision/approval bindings, earliest actual delivery and customer observations remain separate.
6. Record source-backed corrections as later editions, complete named study reviews, then save and export the whole session, originals and readable report.

## Files

- OPERATOR.md explains the browser workflow and complete recovery.
- SOURCE_INTAKE.md explains exact originals, canonical mappings and receipt chronology.
- MEASUREMENT.md explains cohort, authority, arithmetic and person-time interpretation.
- DOMAIN_CONTRACT.md and templates/ give the actual eighteen-family input contract.
- NATIVE.md documents the Node 18+ CLI and source rebuild.
- RECEIVING.md specifies the full real-machine receiving course.
- DELIVERY.md defines a complete reusable handover.
- examples/ contains the complete authored eight-visit course and every canonical input CSV.
- verification/ records actual maintained-source courses and their runtime.
- SOURCE_MANIFEST.json identifies every source master.

The complete session carries unfinished forms and retained branches. A selected CSV or study-only JSON cannot substitute for that session when pending work matters. Download independent complete session files even when browser storage reports saved.
