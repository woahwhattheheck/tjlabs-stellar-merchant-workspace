# Operating the Field Quote Study Desk

## Define the whole case

Choose one real company/team and a completed interval of consecutive visit openings. Include the service kinds to evaluate and retain the source inventory with a page or row locator. The result distinguishes known exclusions from unresolved identity or selection. A blank company or unknown inclusion does not silently shrink the denominator.

The application has two complementary analyses. Return comparison checks original-versus-returned fields, explicit identity maps and linked document bytes. Quotes & delivery study evaluates the independently selected evidence side at its declared cutoff. A one-sided workflow study may be useful while the separate return comparison is incomplete; the report labels both.

## Retain and map actual evidence

Supporting originals accepts exact binary voice, video, photos, notes, quote PDFs and other authorised source files. Common image, audio and video types have an offline preview; every retained file can be downloaded exactly. A preview is not a transcription or a new finding. Same names with different bytes remain distinct.

Use CSV intake & mapping for complete exports. Map each canonical field to an actual column or leave it unavailable. A mapped blank cell is an observed empty value; an unmapped field is null/unobserved. The availability manifest preserves this distinction with selected CSV exports. The original UTF-8 text, including BOM and line endings, remains retained.

For individual observations and corrections, use Observed records. Select a family and evidence side, then prepare an existing row or start a new record. Editing a record creates a later complete selected extract, retaining the previous values, source row and reason. It does not rewrite an older source edition.

Evidence and quote payload records carry exact SHA-256 values. The retained-original helper can copy a chosen document's digest into the pending record. Apply the actual sourced record, then link the original to its typed record in Supporting originals. Copying the digest alone does not record a receipt, approval or delivery.

## Record where evidence was actually available

A local capture and server receipt have separate records. Each evidence receipt identifies the stage (device, server or reviewer), exact receiving identity, actual bytes and available/recorded times. Each supplied output identifies its own producing stage, receiving identity, input cutoff, actual input-use times and model/rule release.

A device receipt cannot establish server availability. For example, an original available on a phone at 10:05 and on a server at 10:35 cannot support a 10:20 server output. A later corrected output remains a separate quote edition. Retain all original versions rather than replacing the earlier input snapshot.

Supporting-document source availability is separate from when this desk imported the file. A source-backed availability correction binds the exact byte digest and previous metadata, retains the old value, and leaves the bytes unchanged. Removing a document link retains the original file and prior relationship.

## Review the actual quote workflow

Quotes & delivery study shows complete visit outcomes first, followed by supplied editions, each input receipt, actual line arithmetic, publication/send/delivery events, exact decision and approval context, customer responses and all recurring effort.

Company authority, company policy and actual decisions remain supplied records. A drafted quote does not establish approval. An earlier approval for a predecessor edition does not approve a changed payload. Actual send_now, review_required and locked decisions retain their source policy, actor, time and reason. An actual invalid or unresolved first delivery is not replaced by a more favourable later delivery for the before-departure result.

Customer viewing, acceptance, signature, rejection and cancellation remain separate observations. They never substitute for an internal approval, an issued invoice or payment.

## Study review and complete handover

Named source and operations reviews concern this complete study. They are separate from the company's operational quote-approval records. Each configured study role reviews the current complete digest. Any source change expires the current review binding. A pending old review retains its notes and must be explicitly restarted for the new edition.

Download the readable report for a sponsor and the full working archive for continuation. The full session includes original files, selected sources, unfinished forms, historical editions, reviews and retained browser branches. All source masters are also downloadable from the standalone application.

## Recovery and concurrent work

The status line distinguishes saved, unsaved, memory-only, branch-conflict and emergency-pending states. File loading reserves the operation before asynchronous reading. Applied imports are validated completely before replacing the selected session. Rejected candidates remain recoverable.

When two tabs diverge, the application retains both complete branches and requires an explicit choice. Choosing a branch acknowledges the currently saved copy in one IndexedDB transaction; it does not erase that copy or fabricate a domain revision. Ordinary subsequent saves then continue from the chosen branch.

Every prepared replacement, reset and changed record draft retains the earlier complete form. If browser persistence or the forty-MiB session limit rejects a normal save, emergency recovery retains the complete pending form or import. Download it before leaving. Opening another complete session first downloads and retains the current session.

The file is offline and performs no network operations. Keep independent session files because browser storage can be cleared. Larger media collections should be scoped into separate complete studies rather than omitting originals from a supposedly complete one.
