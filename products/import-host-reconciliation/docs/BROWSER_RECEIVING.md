# Complete browser receiving course

Record the actual browser/version and opening path when executing this course. The authored example is fictional and separate from blank operator data.

1. Open the blank desk. Confirm zero original/import/plan/reconciliation/review counts. Enter a preparer and an incomplete mapping JSON draft. Save working JSON, close and reopen it; confirm exact unfinished text.
2. Open the clearly authored example. Confirm the prior draft-only session remains recoverable.
3. Inspect the original CSV and captured webhook. Verify leading-zero SKU, multiline text, boolean type and exact large numeric token9007199254740993. Download originals and compare their retained hashes.
4. Copy the selected mapping into a new draft. Change a field rule; preview it. Edit again and confirm the prior preview visibly becomes stale. Restore the selected rule, preview and retain.
5. Copy a parent host plan. Check every create/update/skip action and target, including the skipped reason. Preview and freeze a distinct plan; original remains.
6. Select the first and corrected retained host results. Inspect rejected, uncertain, typed divergence and skipped rows with their expected field values. Confirm original sources and observation coverage remain accessible.
7. Compare explicit baseline/candidate reconciliations. Inspect the changed-source pair, exact row keys and unmatched population. Append a named decision to an actual row; confirm its prior decision remains.
8. Leave incomplete action JSON and an unfinished review note. Export working JSON, editable HTML, domain JSON, full source, selected report JSON/CSV and full ZIP.
9. Cold-open the working JSON and editable HTML. Confirm the exact domain history and pending text. Domain-only JSON keeps immutable records; the full working files also retain unfinished forms and prior sessions.
10. Restore the initial zero-operation draft. Confirm the completed session remains as a prior snapshot; restore it again.
11. Open two tabs, save changes in one, then attempt a save in the other. Confirm the visible conflict status, export both and explicitly choose one while retaining the other.

Run the native source course with node native/receive-desk.mjs. Build with node native/build-desk.mjs NEW_OUTPUT.html. Native/browser observations are recorded only when those actual environments run the course.

For the retained production-controller source operation with explicit in-memory DOM/storage/download adapters, run `node native/receive-controller.mjs`. This separate command exercises the actual handlers and all exports; the real browser observations above remain distinct.
