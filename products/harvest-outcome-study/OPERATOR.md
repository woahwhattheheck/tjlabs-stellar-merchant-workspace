# Operator workflow

1. Open the self-contained Harvest_Outcome_Study_Desk.html. Choose Study scope and enter the actual original and returned source boundaries, source class, rights and reviewers. The separate authored-course button opens a complete example.
2. Retain Supporting originals before importing rows that reference them. Keep the exact filename, bytes, media type, source availability and original context. Select the actual document IDs in the source tables.
3. In CSV intake & mapping, choose one of the 28 record families and source/returned side. Map every observed column explicitly. Leave an absent column unmapped; it remains unknown. Import empty complete families with their literal header when the source proves they are empty.
4. In Selected editions, select each exact complete source extract. The assessment cutoff must cover the selected export, while each source row retains its earlier original knowledge time.
5. In Population & work plan, enter the actual consecutive batch-creation interval, grower/site/key, complete member count and all 28 source row counts. Preserve held, split, unshipped and unresolved batches. Enter both methods and every recurring-work phase.
6. Use Observed records to retain actual corrections. The whole selected extract is guarded against stale drafts. For forecast inputs, forecasts and plan reviews, enter the exact source IDs and use Copy exact supplied source binding. This fills hashes from the selected retained original versions; it does not record an approval or invent a prediction.
7. Review Harvest, forecasts & outcomes. Physical inventory separates created, transferred, dispatched, disposed and remaining quantity. Forecast endpoints retain censoring and unobserved outcomes. Expand exposure, reviewed allocations and actual dispatch to inspect their complete source chain. Inspect Commercial outcomes for actual sold values, credit bindings and outstanding disposition quantities.
8. Reconcile original/returned fields with Identity maps and Return comparison. The original files and explicit field differences remain available. Use Named source review for each configured human role; a stale review cannot accept a changed edition.
9. Save complete file preserves the entire session, unfinished forms and retained branches. Save & recover also exports all source originals, selected tables, reports and application source. If another tab saved a branch, both copies remain available; choose the intended branch explicitly before continuing.
10. Hand over the complete session and source ZIP with the actual source rights and operating context. Reopen the saved session and selected report as part of normal receiving.

A blank end time is an explicitly open interval only where the schema permits it. An unmapped end time stays unknown. Temperature summaries retain their exact observed coverage; the interface does not interpolate gaps. Qualities and currencies remain their original units and meanings.
