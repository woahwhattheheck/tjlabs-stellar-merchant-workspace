# Pipeline delivery study

A complete source-preserving pipeline-job receiver and offline review operator. Open pipeline-desk.html for the clearly marked authored two-edition example, or blank-desk.html for commissioning preparation. See START.md for the complete workflow and RECEIVING.md for actual native/browser acceptance.

The native receiver is Node 20+, uses no third-party dependencies, retains original requests and responses, refuses uncertain create replay, collects all episode pages, streams result files and verifies original byte identities. Large originals remain in the complete native handover directory; the browser envelope labels them explicitly.

The browser never calls the service. It keeps exact originals, independent saved heads/proposals, unfinished source-bound reviews, whole JSON/HTML exports and reports. Local notes do not modify supplier quality decisions. Private credentials, correspondence and commissioned datasets do not belong in this repository.

Public source is pinned in source/openapi.json and source/public-aloha-source.json. The prepared real Hugging Face request is not executed by this package. Authored responses/files are marked and are not an actual service result.

No browser, Node network/streaming or paid/test service run is claimed from the preparation-runtime source exercises. Use the existing selected runtime and complete same-product receiving course before commissioned handover.
