# Product and operating context

The generic Local Placement Study Desk is a source-preserving companion for a real venue/advertiser operating trial. It records supplied authority, inventory, creative, scheduled delivery and actual observations. It is independent of any display hardware, media player, payment service or proprietary advertising system.

The current public Well Seen programme describes early Greater Pittsburgh host and advertiser recruitment, screen/bench/planter formats, category restrictions, host content preferences and actual commercial terms. At research time it explicitly stated that its installed network was still being built. Those pages are context for an actual signed trial; they do not create installed inventory, authority, contracts, approvals or measured exposure.

Actual signed host and advertiser terms control cancellation, payment and installation requirements. The application retains those terms rather than silently resolving public wording differences. Actual source fields make scope, authority, dates, categories, ad share, prepaid components and exact document identities explicit.

There is no live signage implementation, audience camera/microphone collection, inferred unique-viewer count or automatic payment operation in this companion. Its useful output is the complete editable operating account and honest report on supplied observations.
