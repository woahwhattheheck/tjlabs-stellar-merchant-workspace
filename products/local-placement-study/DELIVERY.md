# Complete application delivery

The ordinary application is Local_Placement_Study_Desk.html. It embeds the maintained core, placement model, source/session recovery, original CSV/binary/ZIP helpers, ordinary controller, complete authored example and the full source set. It starts empty and requires no external network dependency.

The source package contains:
- The 25-family source and comparison framework with exact originals, crosswalks and attachment-byte comparison.
- The complete placement domain and readable report/CSV exports.
- The industrial browser editor and complete portable session recovery.
- Native command source using the same model and session.
- Canonical templates and generated header map.
- Original authored input CSVs, complete example study and executable whole course.
- Operator, intake, domain, measurement, native and receiving guides.
- Retained model/controller/native-source execution results.
- A manifest of each maintained source member.

Build the HTML with node native/placement-desk.cjs build-html --out delivery/Local_Placement_Study_Desk.html. It verifies one captured source manifest and uses canonical member ordering. Full source and working export commands are in NATIVE.md.

The authored course contains fictional administrative records and exact authored payloads. It is included to demonstrate the complete workflow and its exceptions. Actual trial conclusions require authorised original records from the real operating scope.

Generated application/ZIP files are complete engineering deliverables. Customer-facing transport should use the actual approved file-sharing route and ordinary readable documents where appropriate. Runtime source does not contain a buyer contact list or send operation.
