# Imagery and processing workspace

Prepare imagery and processing data for customers, operate the original merchant
and receive the complete work on another host.

Use the [operating and receiving guide](./OPERATING.md) for the whole journey:

1. Select and install the source runtime.
2. Discover an actual STAC catalog and acquire a reviewed scene edition.
3. Review retained assets and attach FilmDrop or Cirrus processing history.
4. Save the original imagery, eoAPI or Prescient operator in Applications.
5. Keep the browser and typed agent client on the same saved workspace.
6. Stage the selected edition, run its original customer acquisition and receive
   the exact files.
7. Export the offline scene explorer, receive the full working application and
   reopen after interruption.

The original command is `starforge stac`. Applications provides the
`stac-imagery`, `stac-eoapi` and `stac-prescient` modes. The original typed
client is `starforge stac-workspace`.

[Example requests](./examples) select the existing runtime and private workspace.
Copy them into the host's private configuration directory and replace their
runtime ID and paths with the actual selections. The example receiving request
uses completed source directories and a separate receiving destination.

This product guide is packaged with the original STAC, processing, customer,
Applications and receiving source. Installed archives retain it at
`source/products/stac-workspace/OPERATING.md`.
