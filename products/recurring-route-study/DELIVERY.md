Deliver the working session separately from the application. The application source includes core.cjs, route.cjs, session.cjs, binary/CSV/exact-rational/SHA/ZIP modules, the ordinary browser controller and renderer, native CLI, all canonical templates, complete authored source and reproducible courses. No external network dependency is required to run it.
