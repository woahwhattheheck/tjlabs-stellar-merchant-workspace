This is the self-contained training case for exercising the actual property-continuity application. It supplies clearly labelled authored records, full original files and an executable input to the existing native receiving programme.

| Population | Training journey |

These are separate stages in one software exercise.

## Prepare on the equipped host

Use the final complete application source directory. Its source-selection.json must include this generator and guide, the final domain, application and receiving programme.

Use the existing installed Python, Node, Playwright entry file and Chromium executable. Choose one canonical operation UUID and retain it for this whole case. The original and received directories are created beneath the selected training directory.

Run from the application source directory:

```sh
python3 -B examples/make_training_case.py \
  --directory /absolute/bluewave-training-case \
  --operation-id ORIGINAL_OPERATION_UUID \
  --node /absolute/existing-node \
  --playwright-module /absolute/existing-playwright-entry.js \
  --chromium /absolute/existing-chromium \
  --actor-id ACTUAL_OPERATOR_REFERENCE \
  --actor-name "Actual operator"
```

The command writes the complete original files, training-input.json and training-preview.json. The preview records the selected application source, exact original/following state hashes and derived workflow counts. Existing files are immutable: an exact continuation can reuse them, while conflicting bytes require an explicit new training case.

The generator prints the actual input path, operation directory, input hash and selected source root. Use those exact returned paths:

```sh
python3 -B -m bluewave.receiving_program \
  --input /absolute/bluewave-training-case/training-input.json \
  --operation-directory /absolute/bluewave-training-case/operation \
  --source-root /absolute/final-application-source
```

Keep that input, operation directory and source selection together on continuation. RECEIVING_PROGRAMME.md describes original process custody, the full native phases, complete file packaging and recovery.
