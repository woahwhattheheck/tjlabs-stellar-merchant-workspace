# Operating the Water Operations Study Desk

## Set the source boundary

Start in Study scope. Give the study a useful title and describe the actual original and returned record boundaries. Keep the source class operational for real work; the included fictional example is explicitly authored_course. Record the source rights and people who may review the study. A study label does not confer operating authority.

Set the knowledge cutoff and the half-open scheduled window in Population & work plan. A member scheduled exactly at the start is included; one scheduled exactly at the end belongs to the next window. Use an explicit system or population key when needed. Enter the expected complete inventory only when supported by the source. Unknown counts remain blank.

The twelve laboratory expected counts concern retained original rows, including explicit revisions. They supplement actual records. They do not create missing samples or results.

## Retain originals and map supplied records

Supporting originals accepts PDFs, scans, photographs, laboratory files and other exact bytes. The same name with different contents remains a distinct retained original. Source availability is separate from the import time. To correct availability, use Record source availability and supply the reason; the desk checks the exact document and prior metadata before applying the correction.

Import a CSV through CSV intake & mapping. Inspect its original header and map each canonical field explicitly. An unmapped field is unknown. A mapped empty cell is an observed blank. The raw UTF-8 source, including a BOM and line endings, is retained. Changing a mapping or recording a correction creates another retained extract.

Selected editions chooses the precise source and returned export used for each family. Earlier exports remain available. Identity maps pair exact original and returned IDs; names, PWS numbers, filenames or captions are not automatic substitutes for an explicit mapping.

## Record actual operational history

Observed records exposes all 36 canonical tables. Prepare an existing row correction or start a new observed record. The preceding unfinished form remains recoverable. Saving checks the study and selected extract identity so a correction cannot silently move to a different row after an edition change.

Use an immutable id for each version and a stable record_key for its continuing source record. A later revision names its predecessor. Keep observed, recorded and available instants separate. Do not backdate availability to the physical event when a field device synchronised later.

Approved schedules are supplied records with actual authority and effective periods. Obligations are explicit scheduled occurrences; cadence text is never expanded into invented dates. The exact binding helper copies a schedule hash after the immutable schedule ID is selected. Actual approval remains a separate source fact.

Field readings retain the original value, qualifier and unit. Explicit zero is a measurement when source-backed; nondetect is not zero. A reading review binds the whole exact source row. The helper prepares that hash without inventing a reviewer, decision or time.

Registered asset status is shown separately from observed source use. Record actual source-use intervals and quantities where supplied. A standby registry entry alone does not prove that a well was unused during a reporting period.

## Inspect laboratory evidence

Laboratory records shows every retained order, sample, custody event, accession, report, result, amendment, review and selection. Read the detailed issues on the actual row. Rejected and field-only samples remain part of the population.

Use exact result and prior-report IDs for amendments and reviews. The helper copies the complete laboratory row hash. A partial amendment must specify replacement, withdrawal or carry-forward scope; it does not silently erase the original report. Current reconciliation can be required even when an earlier frozen report was properly supported.

Use the actual laboratory unit, method, qualifier and detection-limit text. This desk does not convert unapproved units or compare results with statutory or treatment thresholds.

## Prepare and review reports

A reporting record retains its document label, claimed reporting period, evidence cutoff, generation time and original PDF. These fields may differ and must not be collapsed. The population inventory remains separate from the report title.

For each report input, select the exact family, retained extract and immutable row. Copy its source binding into the pending form. Supply the meaningful input role and any explicit reason for including an observation outside the claimed period. Preserve all required population-member inputs, including unfulfilled work.

A report review binds the full header and input list. Use Copy current packet review basis after selecting the report identity, then record the actual named reviewer, role, decision and time. A changed source, population or role requirement makes an old acceptance stale. A later review cannot support an earlier send.

Record actual sent, published, received, rejected or withdrawn events separately. A receipt identifies its prior send, actual recipient, channel, external reference and original document. A valid send is not a regulatory acceptance. Duplicate external event observations cannot create additional delivery counts.

## Hand over responsibility

A handover records the outgoing and incoming people, system, actual preparation and effective times, original packet and complete item count. Each item names its exact retained source, responsibility and supplied next due date. Use the same source binding helper for handover items.

The incoming acknowledgement binds the whole packet. Editing responsibility or a source item requires a fresh actual acknowledgement. The acknowledgement itself does not grant treatment authority.

Tasks retain actual assignment, blocked work, completion, cancellation and reopening. A completion must point to the relevant supplied evidence. An unresolved state remains unknown and does not become a false not-overdue result.

## Measure the complete work

Record active person-minutes for each member, method and declared phase. Include recurring confirmation, sync reconciliation, laboratory coordination, review, correction and handover. Do not enter elapsed waiting as active labour. Use a stable work_key so a renamed export cannot count the same work twice.

Every included member needs both methods and every declared phase, including explicit observed zero, before the whole-population comparison is complete. Matched subsets are shown separately. Current-minus-baseline is signed; increases remain visible. The desk does not translate capacity into cash savings.

## Save, recover and move work

Save complete file includes the selected study, every unfinished form, historical study editions and retained branches. Browser storage uses compare-and-swap: another tab's different saved session is retained as a branch, and adopting a local branch requires an explicit action. Download recovery files before moving browsers.

If a full form cannot fit the validated session, it remains in emergency recovery with a visible unsaved status. Complete emergency export preserves the exact form and pending import. Selection happens only after a successor validates; a failed operation does not clear the pending form.

Export the full session, readable report, canonical CSVs, originals and source. Complete exports preserve null-column availability in the selection manifest; a blank CSV cell alone cannot convey unknown versus mapped blank. Keep the complete JSON session when moving the work to another operator.
