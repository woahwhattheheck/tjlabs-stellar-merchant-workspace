# Receiving the complete desk

The source package includes the ordinary offline HTML, complete editable source, 36 canonical CSV templates, the fictional whole-system example, the original laboratory contribution, full saved sessions and maintained source courses.

## Source courses

The maintained courses execute actual domain modules and generated browser handlers. The browser course injects DOM and IndexedDB services; it is not a claim of a visually rendered browser run. The native course injects filesystem and command services; it is not a claim of operating-system execution. The exact result files state the execution mode and checks.

## Actual local receiving

On an equipped computer with Node.js 18 or later, retain the complete source directory and run `node verify.cjs`. Build a fresh HTML output with `node native/water-desk.cjs build-html --out receiving-desk.html`. Compare its SHA-256 with the supplied generated HTML; source order is canonical.

Open the HTML in a current desktop browser. Confirm that the empty study is the initial state. Open the complete authored workflow, inspect all twelve sections, prepare a field reading correction, use an exact laboratory result binding and report review basis, and retain an unfinished form before changing sections.

Save the complete session, close and reopen it, then export the readable report, canonical CSVs, supporting originals and full source. Open two tabs, save different changes, and confirm that the competing complete branch remains available before explicitly choosing which branch to continue. Verify the complete recovery download contains the unfinished form.

Use native prepare-record and record with a new output path. Select a later extract and verify the earlier correction is refused with no output. Export a full session with an arbitrary binary original and compare those bytes after reopening.

Keep actual receiving output, environment versions and any concrete defect report with the delivered package. Do not substitute a screenshot or a successful syntax check for these workflows.
