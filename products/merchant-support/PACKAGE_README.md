## Install the original runtime

Use this archive's actual SHA-256 with the maintained runtime profile and installer. Select the original `schema`, `openapi`, `mcp`, native and operator dependencies, then attach the READY runtime to Runtime workspace. Open **Applications → Merchant support** and select the customer's actual private case, source and package directories.

The optional Handoffs profile connects the original remote receiving sources. The application retains its reviewed native profile identity through startup and reopening.

## Commands

The installed `starforge` command includes `support-console`, `support-watch`, `merchant-implementation`, `merchant-services`, `merchant-commercial`, `merchant-support-agent`, the original merchant MCP launchers, and the maintained runtime installation and transfer commands.

Read the setup command's original options:

```sh
starforge merchant-support-agent --help
```

The setup command creates the original merchant host for an existing Support connection and case collection. Its original release initialization and immutable configuration publication resume in the same selected output.

## Continue customer work

Receive the whole case package through **Complete delivery**, then open the receiving case named by the original completion. Keep that case directory and native source directory together through reopening. The package retains the complete captured sender history and every original native source archive.
