# Operating the complete desk

## Start and save

Open the standalone HTML locally. It has no external dependencies. A new study is empty. Give it a meaningful title, source boundary and actual reviewer context. Complete unfinished forms are retained automatically when browser storage is available. The status bar distinguishes saved, unsaved, working, memory-only and competing-branch states.

Save complete file exports the entire session, including unfinished forms, prior studies and retained branches. Reopen that JSON through Save & recover. Import validates the complete successor before replacing the selected session. A current session is downloaded and retained before a replacement. If another tab has a newer branch, choose the branch explicitly; both originals remain recoverable.

If a form exceeds durable session capacity, its complete pending input remains in emergency recovery and the status shows it. Download that recovery before leaving. A failed file import remains available as an exact candidate. The app reserves file-reading work before awaiting its bytes so it cannot apply an old file to a newly selected study.

## Normal records and CSVs

Observed records provides a full field editor for each of the 21 canonical tables. Starting a different record retains the previous draft. A correction is bound to the exact study and selected extract that the editor opened. A stale correction is refused. Supply actual source revision IDs and dates; editing an imported value does not pretend the external system changed.

CSV intake keeps the entire original UTF-8 text, including BOM and original line locations. Map every supplied field explicitly. Unmapped values remain unobserved; a blank cell in a mapped column remains blank. Select a later extract in Selected editions without deleting the earlier one. Crosswalks explicitly pair original and returned identities; names alone are not identity.

Supporting originals retains exact JSON, images, reports and other authorized bytes. Equal filenames with different content remain separate. Link each document to the correct typed record. Source availability corrections bind exact bytes and prior metadata, with the preceding state retained.

## Requests and actual journals

The request form fills the case's product alias, place and exact dietary profile. Search and Enrich fields are ordinary form inputs. Metadata and Changes may use a nonsecret account alias without a case. Decide requires one explicit retained Search or confirmed Enrich result. Refresh choices explicitly if the study changed after the draft began; the earlier draft remains retained.

Saving a request performs no network call. It produces an exact operation JSON for the native runner. Each operation ID must be unique. The native runner durably records intent before dispatch and returns an existing exact journal without another call when reopened. Read native/README.md for Linux Node 20 and util-linux flock commands.

Import either one receipt or a complete native export. Select the actual importing person, source availability and evidence side. The full native envelope and every immutable, partial or unselected artifact remain retained. Exports that contain only prepared/partial artifacts are useful recovery evidence and create no invented successful request.

A recorded Decide selection is imported from its exact pre-dispatch identity binding. The response remains tied to the actual operation and approved profile. Unmatched or ambiguous Enrich results remain unresolved. An unanswered dispatch stays visible; it is not silently retried.

## Actual adoption and review

Integration results lists every call and offers Prepare adoption only for a valid identity-bound Decide verdict. The prepared record copies the exact identity, response hash, profile hash, recommended wording, risks and verification flag. Enter the actual adoption ID, source version, reviewer, date and channel. Verbatim wording must remain exact. A reviewed adaptation preserves its own actual text and the full original response.

Source-bound review records a named role decision against the complete current study. Edits invalidate current acceptance while preserving old notes. Restarting a review retains the old draft.

Frozen reports additionally carry their own population window, expected cases and required roles. Report inputs use the exact retained-row helper to copy the extract, immutable row and canonical hash. Source roles describe the actual evidence: case_population, request_journal, profile, adoption, effort and the other documented role values. In report_reviews, enter the report ID and use Copy current report review basis to bind its complete input list before recording a named decision. Changed inputs make that review stale.

## Read results

Whole-population rates require a reconciled expected inventory and explicit case inclusion. Successful HTTP responses are not final fit decisions. Provider confidence remains provider output. Displayed risk and verification context remain attached to the exact profile and response.

Usage shows every actual dispatch, known modelled credits and unlisted prices separately. Monthly header observations are snapshots. Only unique source-backed provider ledger entries contribute to observed incremental charges. Duplicate canonical aliases never multiply a real dispatch.

Corpus snapshots compare the product's own source-place keys and mapped Compass IDs. Complete Changes pages do not establish a complete city corpus. Preserve full inventory before and after a rebuild or remapping operation.

Recurring effort includes intake, selection, implementation, review, correction, reconciliation and feedback. Record real active person-minutes and explicit zeros. Empty or missing phases are incomplete. Signed differences are observations for this matched scope, without cash or causal inference.

## Delivery

Download the readable report for human review, the complete study ZIP for original evidence and editable CSVs, and the complete application source ZIP for engineering receiving. Move the complete session JSON when you need unfinished forms and every retained branch. Existing files remain immutable in the native exporter; choose a new output name for a different successor.
