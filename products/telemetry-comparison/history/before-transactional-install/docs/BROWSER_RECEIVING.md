# Complete browser receiving course

Run this existing course in the target browser on the exact built source. Record browser/OS, source SHA, date and observed result. Source execution with DOM/storage adapters is retained separately.

1. Open the blank standalone desk. Confirm zero originals, editions and reviews. Use a new browser storage context or retain an existing session with Open and restore.
2. Retain a clearly authored CSV original, inspect its exact columns and values, and download the original. Verify the bytes match. Open the separate authored example and confirm the earlier one-source session remains restorable.
3. Select the corrected-observation baseline and candidate model reports. View scope, points, runs, coverage, metrics, findings, occurrences and pairs. Confirm exact rational values and approximate RMSE labels are readable.
4. Copy the candidate into a successor input. Name the preparer. Select its observation source, inspect it, prepare its explicit stream mapping and replace that exact stream ID after preview. Keep clock and unit choices explicit.
5. Edit a point record and a stream's full JSON. Leave an incomplete quality-list JSON draft, switch sections and return. It must remain visible. Repair it or retain a backup before discarding.
6. Preview and freeze the complete successor. Change one scope field after preview and confirm the save is invalidated. Re-preview before freezing. Prior reports must remain unchanged.
7. Select baseline and candidate explicitly in Compare models, then show the comparison. Review common observations, each side's extra pairs, exclusions and model/calibration context. Different run IDs are unmatched; they are not combined.
8. Retain a named review against the selected edition. Leave an unfinished next review, incomplete input JSON and incomplete mapping JSON. Save working JSON and editable HTML.
9. Reopen each in a fresh browser context. Confirm source hashes, frozen editions, reviews, all unfinished text and retained prior sessions. Received working files with invalid UTF-8 or changed carrier hashes must reject without replacing current work.
10. Export complete report JSON, full report CSV, pair CSV, readable HTML and Markdown, and comparison JSON/CSV. Check full counts against the frozen report. Pagination must not truncate exports.
11. Download full application source and materialize with the included standalone Python helper. Rebuild using the documented Node builder. Verify the same selected source manifest; no runtime network dependency is required.
12. Download the complete handover ZIP; reopen its working JSON and editable HTML. Check every original source and manifest. Use a second tab to create a browser-storage conflict; the first tab must retain its current session and require an explicit copy selection.

The full source-native controller course executes these production handlers with explicit minimal DOM/storage/download adapters. It does not replace a target browser visual observation. Large calculations paint a working notice before saving drafts and invoking the synchronous core; allow the actual operation to finish.
