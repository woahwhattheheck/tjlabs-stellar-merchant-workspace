# Maintenance Incident Knowledge Study Desk

Open Maintenance_Incident_Knowledge_Study_Desk.html in a browser. The complete application works offline and starts with an empty operational study. It includes ordinary source-intake and record-editing screens, actual-output evaluation, knowledge and handover review, active-work and downtime observations, full portable saved work and a shared-model native command.

The first-team study joins actual machine/configuration and incident records, the symptoms known at each supplied diagnosis, original model outputs, later confirmed cause sets, exact approved knowledge editions and shift activity. It preserves incomplete and unresolved evidence instead of filling it in.

## First useful run

1. Read DOMAIN_CONTRACT.md and agree one plant area, machine family, consecutive incident window, original source owners and evaluation stage.
2. Open the authored first return to learn the workflow. Its five differences comprise three changed fields and two changed-document findings.
3. Open the authored corrected return. It has zero original/returned differences; its ten eligible incidents still include two abstentions, one failed output and two unresolved cause outcomes.
4. Start an empty study. Import authorised source CSVs, map original columns explicitly and retain actual diagnosis/knowledge/inventory originals.
5. Define the complete population and cutoff. Review source availability, actual input provenance, confirmed-cause scope and the three denominator views.
6. Record actual named source reviews, export complete work and reopen the saved session.

The desk does not connect automatically to a CMMS or production system. It accepts supplied source exports and originals; a connector or machine telemetry feed is not required to receive the application.

## Use the right measure

Conditional ranking rate describes valid ranked outputs with confirmed outcomes. Confirmed-cohort coverage also includes abstentions, failures and missing/invalid outputs. Observed whole-cohort success keeps all eligible incidents and explicitly shows unresolved causes. A successful matched subset is not a complete-population result.

Active person-minutes include confirmation, knowledge review, reconciliation and handover. Machine-stop intervals are a separate union calculation. Neither measure is automatically a cash saving.
