## Operate each actual copy

Import operateEventWorkbookColleagueCopy from this file. In addition to the common inputs above, pass role: 'producer' or 'reviewer' and an explicit edits array. Each entry is:

    {
      sheet: 0,
      expected_columns: [ /* entire original ordered array */ ],
      columns: [ /* entire operator-selected desired ordered array */ ]
    }

The sheet value is the actual original proposal's integer worksheet index. expected_columns must match its complete original array exactly. The selected source is its exact original source name and, for report sources, source_index ordinal. The model rejects ambiguous or unavailable source selections. Empty edits is an explicit decision to retain this copy's choices. Extra resolved arrays remain complete and unchanged; no guessed names or positions join them.

The module selects the original worksheet, adds/removes output columns, sets the complete source selection, heading, type, null behaviour, dormant null label and precision through the actual existing UI controls. The desired values are normalized through the original complete model before the UI is operated. A blank null choice still preserves its complete dormant label.

For the reviewer, also pass actor and returnNote. Both must be the actual attributed operator text. The real UI records these through its original fields. Its Download complete returned review button creates the attributed original timestamp and complete return envelope; the helper never fabricates that timestamp.

- complete-editor.html with every original source, all arrays, unfinished notes and review history;

## Parent cancellation and browser lifetime

Pass the existing parent's AbortSignal as signal. The phase checks it before each borrowed browser or locator operation and after awaited browser results. Once cancelled it initiates no later edits, downloads, navigation or screenshots. An already in-flight caller-owned Playwright operation is allowed to settle under that parent's configured timeouts; the helper does not close or replace its pages to force cancellation. Its temporary dialog listener is removed and a changed capture viewport is restored as cleanup. Cancellation also brackets original recovered-download reads before publication. Already retained complete files and download request/path records remain available to the same continuation. ## Original downloads and interruption recovery

Every download is an original byte stream retained through the maintained atomic file writer. The helper records its request before clicking and retains the original browser download path before publishing the complete file. Its file identity accompanies the original artifact. On rerun it reopens completed outputs and checks their exact identities.

If a request was issued but its complete file was not retained, pass recoverDownloads as a map from the exact requested filename to the actual recovered browser download path. The helper validates that whole file against the original source and expected working state, then continues the same phase. It does not click again to manufacture another attributed reviewer return. If the original download is unavailable, retain the incomplete phase and recover it from the existing browser's downloads before continuing. No downloaded file or incoming source is silently replaced.

The final complete.json lists all whole files and captures. A rerun verifies those files and returns the original completed result; it does not repeat browser edits. The current source-native stage/apply operations remain independent and reusable from their own complete retained files.
