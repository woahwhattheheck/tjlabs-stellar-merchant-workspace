## RIS source review

The installed Research workspace retains original RIS files, complete record occurrences and duplicate decisions with the dossier. Open **RIS sources** to prepare a source edition, inspect every original record, save and reload a full review draft, receive the reviewed edition in one dossier revision, and compare a later review with its predecessor. Original files remain available alongside the declared selected-RIS and review exports.

Use `starforge research-ris` or the existing `starforge research-client ris-*` commands against the same identity-checked listener. `ResearchWorkspaceClient.risSources()` and the original Merchant Research attachment expose that same source, request and revision history. `starforge research-ris-receiving --selection /ABSOLUTE/PRIVATE/RIS_SELECTION.json` runs the selected complete browser, Merchant and fresh-process receiving programme.

Start with [the installed RIS operating chapter](OPERATING.md#review-original-ris-source-editions), [the complete receiving chapter](RECEIVING.md#19-receive-the-complete-ris-source-review), [full RIS operations](../../stellar/scf-starforge-20261009/sf88-operator-buyer-cli/research-dossiers/ris-source/OPERATING_GUIDE.md) and [full RIS receiving and packaging](../../stellar/scf-starforge-20261009/sf88-operator-buyer-cli/research-dossiers/ris-source/RECEIVING_GUIDE.md). The complete source selection includes the current Research Commerce family, Python package, scientific reference files and original browser assets.

## Start from an existing customer handover

Use `research-customer-handover-intake` when continuing an original published customer delivery. Select the actual dossier and delivery, inspect its complete saved handover and the current native head, and review explicit round, item and source limits before preparing the selection. The intake freezes that reviewed baseline and launches the existing handover desk with its same operation and original native API. Draft scope remains recoverable before preparation; the prepared selection and accepted request identities remain stable afterward. [HANDOVER_INTAKE.md](../../stellar/scf-starforge-20261009/sf88-operator-buyer-cli/research-dossiers/customer-updates/HANDOVER_INTAKE.md) contains the complete first-use commands, browser journey and original-input receiving course.
