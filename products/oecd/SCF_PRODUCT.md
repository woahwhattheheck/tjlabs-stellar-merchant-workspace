# SCF product workflow: retained economic editions

The OECD product is a complete analyst-to-customer application on the existing Stellar Forge merchant and buyer. A data publisher keeps original source responses and revisions, reviews a cross-country economic briefing, publishes its native dataset under the configured payment terms, and delivers the customer's full saved edition with portable reports and source acknowledgment.

## Concrete customer operation

| User | Complete product action | Saved output |
| --- | --- | --- |
| Analyst | Retain original monthly OECD data and matching structures; choose countries, report months and notes | Immutable source capture, native source project revision and exact briefing |
| Publisher | Compare editions and activate the selected customer publication | Native catalog edition, original dataset export and source lineage |
| Merchant operator | Prepare and run the maintained release with existing payment/facilitator settings | Original merchant release/process and actual published offer |
| Buyer | Review the offer and continue the configured original dataset under explicit limits | Native intents, accounting continuation and complete verified DatasetDelivery |
| Customer | Open the offline report or import the complete revised project in a fresh workspace | Original sources, native catalog history, five report files and functioning saved application |

The source-selected **oecd** package includes the complete industrial browser, typed client, CLI, MCP and Applications registration. It composes the maintained SDMX/Macrobond source and catalog model plus the native Stellar merchant/buyer. A customer's own later notes and source editions continue in that same reopened model.

## Demonstration an equipped owner can run

The original source-only demonstration is one command:

~~~sh
starforge oecd-product create \
  --runtime /srv/starforge/runtimes/oecd \
  --project /srv/starforge/projects/oecd \
  --operation oecd-original-briefing-20261013
~~~

It retains the original source, saves two complete native editions, exports the revised project, reopens it in a separate named customer workspace and compares every report file and original row. Its returned JSON names the real reports, ZIP, native edition IDs, customer directory and browser commands.

The complete configured economic demonstration is:

~~~sh
starforge oecd-product receive \
  --runtime /srv/starforge/runtimes/oecd \
  --project /srv/starforge/projects/oecd \
  --config /srv/starforge/private/oecd-receiving.json
~~~

The configuration belongs to the actual equipped merchant/buyer owner. It uses the existing signer and account, actual accepted terms and explicit atomic spending limit. The maintained native receiver completes the two data pages for this 231-row edition, original accounting and delivery, then opens the revised customer project and native provider.

The full operator and continuation contract is in [RECEIVING.md](RECEIVING.md). The actual receiving result supplies the runtime/source pin, original process handle, source/customer artifact identities and native dataset outcome for the programme's result table.

## Original source and report substance

The bundled capture comprises 231 monthly observations for Canada, Germany, France, the United Kingdom, Italy, Japan and the United States. It preserves fifteen complete original responses: data, exact dataflow 4.1, matching DSD 4.1 and twelve referenced code lists. Their 236,642 bytes, original URLs, hashes and acquisition receipts travel with the edition.

The analyst report retains original value text, dimensions, status, declared decimals, multiplier and source actions. It compares countries at the latest calendar month available in every selected numeric series and computes one-, three- and twelve-month differences with exact Decimal arithmetic. Missing values and calendar gaps stay visible. The report's selected date window and full captured native customer series have separate displayed counts.

The new five-file report includes offline HTML, structured JSON, complete CSV and two source-rights companions. Existing saved three-file report versions reopen with their original rendering. The complete revised project keeps native catalog/source history and reconstructs the exact retained report after fresh import.

The [OECD indicator definition](https://www.oecd.org/en/data/indicators/composite-leading-indicator-cli.html) describes a qualitative turning-point indicator with long-term average 100. The product retains that interpretation alongside the original [methodology and revisions](https://www.oecd.org/en/data/insights/data-explainers/2024/04/composite-leading-indicators-frequently-asked-questions.html) and source annotations.

## Recurring customer service

A publisher can commission a recurring selected-country briefing, a source-qualified dataset edition, or the complete customer workspace. A following source refresh retains its actual native response before review; a following analyst save creates the corresponding source/catalog revision. Customers can receive a portable report, query the original Macrobond-compatible publication, or continue the full saved application.

The product's engineering deliverables support customer commissioning around source coverage, useful report selections, publication settings and complete installed receiving. The original maintained merchant controls actual payment behavior, and the configured buyer controls the accepted economic operation.
