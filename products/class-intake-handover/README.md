# Class Intake Handover

Complete source, local operator, typed client, CLI, source-bound Berea example and independent receiving are in [`class_intake/`](../../stellar/scf-starforge-20261009/sf30-seller-sdk/class_intake/README.md).

The product retains a whole class catalogue plus separate registration, payment and instructor-confirmation inputs; saves named source corrections and matches; prepares a documented hidden CourseStorm import sheet; and exports/reopens complete source and request history. The operated example labels all generated registration and payment records as engineering data. Native and browser completion are reported separately by their actual receiving outputs.

48DB retains the original CourseStorm commercial conversation. The source package performs no provider mutation or customer send.
