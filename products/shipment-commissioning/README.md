# Shipment Commissioning Desk

A complete local operator for commissioning shipment document changes against approved reference checkpoints. Retain originals, map exact provider output, capture full observations, review bindings and protected fields, record comparable work, and export every source and history edition.

Open Shipment_Commissioning_Desk.html for the standalone editor. The authored worked example demonstrates ambiguous document references, protected field changes, repeated amendments and late older input. Use the normal forms to create your own approved cases and actual captures. See docs/OPERATOR.md, docs/CONTRACT.md and docs/COMMANDS.md for complete workflows and exact command contracts.

The installed edition adds Applications create/open/resume, one private writer, complete browser recovery, native commands, MCP and full-source compressed handover. Customer research and commercial programmes remain separately retained in their original private case.
