# QGIS and QWC publications

Publish a saved native GIS map through an existing QWC installation and hand
its complete source, project, generated configuration and operating history
to another operator. The product retains the original selected data and QGIS
workspace throughout preparation, publication, refresh, scoped restore and
independent receiving.

The neutral private browser and native CLI operate the same original
publication workspace. **QWC publications** is its maintained Applications
entry. The selected existing QWC service remains the actual map viewer.

## Install the complete product

Use the source-owned `qwc-publication` selection and the maintained runtime
installer. The complete installed operating guide is:

[QWC publication installation and customer receiving](../../stellar/scf-starforge-20261009/distribution/selections/QWC_PUBLICATION.md)

It covers source build/resume, the exact installer profile, host and saved-map
selection, Applications Review/Save/Start/Open/Stop, real role/map/feature/print
acceptance, publication and refresh/restore, complete archive receiving and
native QGIS reopen. The package README is this full operating guide.

## Customer source and operator

The original implementation lives at
[stac/qwc](../../stellar/scf-starforge-20261009/sf30-seller-sdk/stac/qwc/README.md).

[Editable inputs](../../stellar/scf-starforge-20261009/sf30-seller-sdk/stac/qwc/examples)

[Complete native receiving](../../stellar/scf-starforge-20261009/sf30-seller-sdk/stac/qwc/NATIVE_RECEIVING.md)
joins both deployed editions, the original independent acceptance operator,
host restoration, both private consoles and the whole customer ZIP.

## The complete delivered edition

A receiving includes the original GIS archive and actual data files, native
project and layer identities, original and effective QWC configuration,
publication/deployment history and complete native receiving records. The
customer driver produces both original publication handovers, the independent
acceptance handover and one complete customer archive with their exact
manifest and SHA-256.

Retain the source archive/manifest and actual runtime tuple alongside the
private publisher and customer artifacts. Each intentional new source edition
uses the maintained builder's new output; resumed operations keep their exact
original request, workspace and source.
