# Warehouse Activity and Billing Study Desk

Open Warehouse_Activity_Billing_Study_Desk.html in a modern browser. The complete operator works offline and starts with an empty study. It provides ordinary forms for sources, clients, warehouses, rates, activity imports, actual invoices, accounting observations, source-backed reviews and recovery.

The purpose is a complete one-month review alongside an existing WMS and billing process. Original exports and exact mappings remain available while the operator explains each proposed charge. Issued invoices and accounting/payment responses are supplied records. The application performs no external system actions.

## Start with a useful complete month

1. Open the labelled worked month from Study scope. Inspect the complete and missing-day versions, then start a new empty study for operational inputs.
2. Retain the source inventory and agreed rates in Supporting originals. Create or map the canonical client, warehouse and source-system records.
3. Define the billing month, knowledge cutoff, all additive source partitions, clients, warehouses and storage scopes in Month & billing plan.
4. Import each whole activity file using Raw activity import. Review the actual source row basis and explicit replacement predecessor.
5. Inspect Billing & actual records. Resolve source identity, unit, count or rate exceptions using retained source corrections. Use explicit source-backed waivers only where offered.
6. Add actual invoice records, their lines and supporting original documents separately. Import actual accounting responses with their own account, observation and recording times.
7. Record each named review against the complete current study, then export the readable report and full editable working archive.
