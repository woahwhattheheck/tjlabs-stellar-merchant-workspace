## Retained services, facilitator choice and complete receiving

A merchant can change its payment provider while keeping the selected service, source edition and customer work together. The existing Socrata Publisher supplies that workflow in its browser, CLI and merchant MCP interface: choose the retained release and configured provider, inspect the complete native payment alternatives, retain the review and stage that reviewed release. The merchant then uses the existing activation, rollback and seller controls to select and run it.

### Work with the complete observed provider response

The [received-response implementation and operating guide](https://github.com/woahwhattheheck/tjlabs-stellar-merchant-workspace/blob/1b1c24ffb138ae6c1a60f5addd62e485ddddf37d/stellar/scf-starforge-20261009/sf82-seller-pilot/FACILITATOR_RESPONSES.md) lets an available public source reader supply the whole provider response to the original operator. The portable document retains its endpoint, retrieval window, source attribution, content type and every original byte. The host profile selects the endpoint; the received document must match it.

The installed x402 SDK interprets those bytes and resolves the original service's complete ordered payment requirements. Its normalized value and the full original body remain separate, inspectable representations. This matters when a provider includes catalogue fields outside the SDK's supported-payment schema: an asset mentioned in a catalogue does not silently become an accepted payment alternative. The saved review binds the chosen host, original release digest, selection generation, normalized capabilities and exact native terms.

An operator can reopen a completed review and reconcile its already staged release after an interrupted reply. Changing the provider, source selection or captured document requires the matching review. The [Publisher guide](https://github.com/woahwhattheheck/tjlabs-stellar-merchant-workspace/blob/1b1c24ffb138ae6c1a60f5addd62e485ddddf37d/stellar/scf-starforge-20261009/sf30-seller-sdk/socrata/FACILITATORS.md) connects that retained work to release activation, seller startup, rollback and complete merchant-file receiving.
