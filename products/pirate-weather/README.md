# Pirate Weather forecast reports

This selected Starforge product keeps an actual customer's report contract, original forecast responses, reviewed 48-hour report editions, native datasets/releases and complete received project in one private workspace.

The source-selected package includes the browser, CLI, typed client, MCP provider, managed Applications registration and trusted complete-project receiving. It reuses the original SF30 dataset publisher, SF82 merchant release and SF88/SF100 Buyer outcome engines.

## Start here

Prepare and install the actual source archive through the maintained runtime-install workflow. Initialize one empty private workspace with pirate-weather init, then open it with pirate-weather serve or the original Applications manager. Provider requests are explicit, and the API key remains a host environment reference.

The full [operating guide](../../stellar/scf-starforge-20261009/sf30-seller-sdk/pirate-weather/OPERATING.md) covers source selection and installation, actual contract/source intake, named review, native delivery, saved request recovery, complete-project transfer and cold installation with the original dependency lock.

See the [source contract](../../stellar/scf-starforge-20261009/sf30-seller-sdk/pirate-weather/SOURCE_CONTRACT.md) for exact forecast-number tokens, coordinates, units, UTC windows, coverage, response metadata, quotas and original source meaning.

## Included workflow

| Stage | Result |
| --- | --- |
| Contract | Actual customer, purpose, destination, one to three locations, units and two review slots |
| Source | Exact response bytes and original request/HTTP/body/usage evidence |
| Report | Explicit 48-hour projection, coverage, comparison and named approval |
| Native delivery | Original dataset, release selection/control and selected Buyer outcome |
| Complete project | Source package, source/decision/native history, prior issued archives and original runtime source/profile/lock when available |
| Receiving | Same-source verification, native path adoption, cold preparation and original workspace reopen |

Forecast values remain forecast values. Missing data remains missing. This product does not silently schedule provider calls, send messages to the stated destination, create purchases or manufacture a customer forecast.

The source publication is separate from an actual customer operation. An empty application can be initialized and received without a provider key; real report and provider acceptance requires the actual customer contract/source and designated operator.

The maintained recipe is stellar/scf-starforge-20261009/distribution/selections/pirate-weather.json. The generated manifest binds every included source byte to its selected Git source. Preserve the original archive/manifest and use the same trusted application edition for receiving.
