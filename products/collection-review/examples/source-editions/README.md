## Reopen and replay

Run from the repository root using the existing installed Node runtime. All output names must be new; the CLI never overwrites an unrelated file.

```sh
node stellar-forge/developer-site/collection-review-cli.mjs show --project products/collection-review/examples/source-editions/Collection_Review.json
node stellar-forge/developer-site/collection-review-cli.mjs save --project products/collection-review/examples/source-editions/Source_Edition_Basis.json --request products/collection-review/examples/source-editions/Original_Edition_Request.json --out /absolute/selected-output/replayed-collection.json
node stellar-forge/developer-site/collection-review-cli.mjs receive --project products/collection-review/examples/source-editions/Source_Edition_Basis.json --incoming products/collection-review/examples/source-editions/Collection_Review.json --out /absolute/selected-output/received-collection.json
node stellar-forge/developer-site/collection-review-cli.mjs serve
```

Select real output paths on the existing operator's machine. The receive result deliberately keeps the local selected revision and adds the received history; choose the received revision explicitly when desired. Replaying Original_Edition_Request.json against the already-saved result returns its same original revision. It does not add another review.

The browser uses the existing same-origin IndexedDB writer. Open Source_Edition_Basis.json, choose the earlier TMU source and structured replacement, review correspondence and carry choices, prepare/save, change local text before recovery, download, then cold-reopen the complete output.
