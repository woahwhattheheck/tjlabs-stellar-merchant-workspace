# Grant portfolio application

Receive complete publisher sources, deliver programmes and funding rounds, operate
the selected staff workflow, and hand over an application that reopens with its
original sources, documents and full working history.

The product uses one saved native workspace through its browser console, Applications
launcher, Python CLI, typed clients and merchant tools. Source reconciliation retains
the original IATI and 360Giving editions, their entities and financial rows, reviewed
links, decisions, unmatched coverage and later-edition changes. Programme delivery
and applications/awards add their own revision-pinned registers to that same portfolio.

| Work | Complete application capability |
| --- | --- |
| Source reconciliation | Receive complete publisher packets; review entities, links and decisions; select following editions and retain exact financial meanings. |
| Programme delivery | Projects, partners, grants, milestones, results, risks, issues, documents, submitted reports and closure. |
| Applications and awards | Funding rounds, application intake, eligibility/diligence, assessor disclosure, assessments, panel decisions, agreements, claims and monitoring. |
| Application exchange | Reviewed full CSV mapping and stable record identities; original CSV plus applications saved together; selected JSON/CSV export. |
| Staff operation | The selected native project process, source-bound evidence and QA decisions, accountable clearances, corrections and command history. |
| Dataverse delivery | Reviewed original specification and target, native deployment, configuration and complete managed/unmanaged solution handover. |
| Continuing support | Original defect reports, agreed service clocks, retained corrections, installed-release validation, closure, reopening and complete support delivery. |

Amounts preserve decimal text, currency, financial meaning, source, date and reporting
period. Programme results preserve their units, dimensions and observation periods.
Published or submitted records retain their contributing editions. Uploaded document
bytes stay attached to their original history through export and receiving.

The current staff and Support profiles implement the issued SPC project process and
service obligation. Select that profile for matching work; another customer's agreed
process or service term requires its explicit source adaptation. General portfolio,
programme and award work retains the actual selected source and approved rules.

## Install and operate

Build the committed `grant-portfolio` source selection with the maintained distribution
builder, prepare and install its runtime, then prepare the private product:

~~~sh
starforge grant-portfolio-workspace prepare \
  --runtime /srv/starforge/runtimes/grant-portfolio \
  --directory /srv/starforge/products/grant-portfolio \
  --python /srv/starforge/python/grants/bin/python \
  --title "Grant portfolio"

starforge grant-portfolio-workspace open \
  --directory /srv/starforge/products/grant-portfolio --port 0
~~~

The command prints the complete local console link. The same prepared workspace appears
under **Applications → Grant portfolio reconciliation** when selected in the Runtime
workspace. Preparation retains the original runtime, interpreter and workspace identities,
plus Applications settings and merchant setup files. Prepare around an already received
native workspace using its explicit absolute `--workspace` path.

The installed archive carries every member of the maintained
[`source-files.json`](../../stellar/scf-starforge-20261009/sf30-seller-sdk/grant-portfolio/source-files.json),
the original IATI and 360Giving receiving engines, publisher schemas and assets,
and the product, Applications and merchant interfaces. The distribution manifest
identifies each selected file by Git blob, byte length and SHA-256.

Choose the complete portfolio, native deployment or support handover for the work
performed. Receive it through its original application path, inspect the returned
workspace and portfolio identities, continue the ordinary customer work and reopen
that same saved history.
