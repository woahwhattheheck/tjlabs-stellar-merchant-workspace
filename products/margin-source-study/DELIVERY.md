# Complete application delivery

The package contains one offline HTML application, its complete maintained source and dependency closure, eleven blank CSV templates, eleven complete authored input CSVs, first/corrected full studies, eight readable guides and reproducible course source/results.

The HTML starts empty. It includes ordinary source mapping, retained selected editions, editable source observations, explicit identity maps, supporting originals, comparison plans, current margin observations, named operations/finance review and whole-session recovery.

The initial authored return has three field differences: changed output, duplicated included agency cost and a half allocation. The corrected return matches while all 25 originals remain retained. The matched Plant A example has +50 USD fixed-reference-volume cost change and −50 USD actual-current-volume change, demonstrating the separate effect of mix/volume. Its ledger margin is 3,000 USD and its accepted cash record 75 USD, with neither manufactured from a benchmark delta.

SOURCE_MANIFEST.json identifies complete source members. The HTML is generated from those source members and the manifest. The full source ZIP includes the HTML and all maintained members. Business-study originals remain inside the portable study/session and its working export.
