# Margin Source Study Desk

This complete source also installs in Applications with the private host, native and Merchant MCP interfaces. See INSTALLED_OPERATION.md for the installed workflow and INSTALLED_RECEIVING.md for native receiving.

Open **Margin_Source_Study_Desk.html** in a browser. The application starts with an empty study and has no external network dependencies. Use the clearly labelled authored example to learn the workflow, or import authorised reports from an agreed plant study.

The desk keeps original and returned CSV editions, arbitrary-column mappings, explicit identity maps, supporting file bytes and corrections. It calculates a defined direct-labour/output view, separate source-ledger gross margin, matched SKU comparisons and a separate benefit register. Operations and finance review the same complete source edition.

## Start an actual study

1. Save the scope: selected sites, systems, periods, source owners and original/returned boundary.
2. Import and map the eleven tables. Record when each complete extract edition was actually available. Use the source system's exact IDs and retain original definitions.
3. Select the intended editions. Resolve explicit identities and source differences in the return comparison.
4. Define the as-of instant, physical unit, accounting currency and basis. Configure one or more matched site/period comparisons.
5. Reconcile economic pools and complete allocation shares. Review production coverage, accepted output definitions, fiscal periods and source availability.
6. Read Margin observations. Review output, labour, hours, physical yield, finance and benefit observations separately.
7. Record current operations and finance decisions. Download the complete session and working ZIP.

The application retains unfinished forms and previous editions. Browser storage is a convenience; **Save complete file** creates the portable recovery copy. All ordinary saved sessions can be reopened in the browser or used by the native command line.

## Included files

- OPERATOR.md: complete working sequence and recovery.
- MEASUREMENT.md: definitions, exact arithmetic and interpretation.
- SOURCE_INTAKE.md: canonical columns, source and coverage rules.
- NATIVE.md: Node 18+ commands and full source rebuild.
- DELIVERY.md and RECEIVING.md: package contents and receiving workflow.
- templates/: empty editable CSV headers.
- examples/input/: complete clearly authored CSV inputs.
- examples/first.study.json and corrected.study.json: retained complete example editions.
- verification/: results of executing the maintained production source with declared injected services.
- operator/run-course.cjs: reproducible whole-course runner.

A study observation or recorded review does not write to operating systems. The actual ERP, payroll, agency, production and accounting records retain authority.
