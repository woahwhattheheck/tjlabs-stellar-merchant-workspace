# Maker Production Workbench

Open Maker_Production_Workbench.html for an empty maker workspace, or Maker_Production_Worked_Example.html for the complete authored three-edition course. WORKBENCH.md covers actual browser operation and recovery. OPERATE_MAKER_PRODUCTION.md defines the eight-table production semantics and native commands. RECEIVING.md carries the existing owner instruction for actual rendered/native receiving.

Build both standalone applications with `node build-workbench.mjs NEW_DIRECTORY`. Run the focused production course with `node run-course.mjs NEW_COURSE_DIRECTORY`. No dependencies or credentials are required. Native outputs use new directories and preserve complete original sources.

The engine plans from maker-declared durations, yields, comparable resource units and compatibility groups, then records actual stage snapshots. Ready-stock, ship and delivery targets are explicit. The authoring example supplies no process parameters for a real studio.
