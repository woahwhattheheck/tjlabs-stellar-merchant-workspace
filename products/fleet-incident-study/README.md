# Fleet Incident and Useful Work Study Desk

Open **Fleet_Incident_Study_Desk.html** in a current desktop browser. The complete application is embedded in that file, starts with an empty study and works without an external service. Use **Load authored course** to explore the supplied fictional example. Save a complete session before moving between computers or browsers.

The desk supports a whole supplied-record workflow: retain originals; map original and returned CSV fields; resolve record identities; describe the actual fleet application and complete eligible assignments; distinguish rental time, engine meters, operating intervals and useful output; reconstruct incident knowledge at a past cutoff; reconcile actual costs and cash; record human review; and export the complete study.

## What the example demonstrates

The authored course has three consecutive comparable forklift assignments, including a zero-output failure. It retains 220 accepted moves and USD 2,200 of recognised net operator expense, giving exactly USD 10 per accepted move. A USD 1,000 payment is shown separately. One asset's overlapping breakdown logs represent 45 asset-minutes, while the interrupted job represents 20 minutes. Each assignment's 540 minutes out on rent stays separate from engine-meter change.

The full recurring work comparison retains seven phases: 70 baseline person-minutes and 56 current person-minutes, a signed change of −14. Later repair findings remain visible in current review and absent from the earlier frozen input set. These figures belong to the authored exercise.

## Files to use

- **OPERATOR.md**: complete ordinary editing and recovery journey.
- **SOURCE_INTAKE.md**: the 24 source families, mapping and exact time/identity conventions.
- **MEASUREMENT.md**: useful-output, interval, financial and effort accounting.
- **DOMAIN_CONTRACT.md**: implemented rules and historical dependencies.
- **NATIVE.md**: Node 18+ commands and complete native session handling.
- **RECEIVING.md**: source verification and an actual OS/browser receiving course.
- **DELIVERY.md**: package contents, source identities and export choices.
- **DOMAIN_HEADERS.json** and **templates/**: exact canonical column names.
- **examples/**: complete fictional study, source CSVs and readable report.
- **verification/**: retained results from the maintained modules and handler courses.

The desk observes and reconciles supplied records. A named reviewer remains responsible for conclusions, contractual treatment and equipment decisions. It retains attributed supplier outputs alongside the actual records used to assess them.
