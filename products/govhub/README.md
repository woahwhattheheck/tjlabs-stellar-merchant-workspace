# GovHub site operations

GovHub is a local operating application for complete site source capture, reviewed content and release changes, native recovery and private project handover. It keeps original source bytes, provider/workflow identities, operator decisions, command output and complete editable workspace backups in one saved project.

## Open the installed product

Choose the **govhub** source selection in the existing Source Builds interface or use the repository's original distribution builder with --selection govhub. The contribution adds **Applications → GovHub site operations** and the **starforge govhub** command. The installed source contains the complete Python application and all provider, content, visitor, release and receiving components.

Use an existing POSIX host with Python 3.11 or later and SQLite support. The managed application uses the selected host's Python; it does not install or authenticate external providers. Node runs only the installed command/Applications integration. Drupal, PHP, Drush, Git and each provider's CLI or account remain explicit native inputs described by their own guide.

1. Read [OPERATING.md](OPERATING.md) and initialize a private workspace using the original CLI.
2. Open that same workspace and supplied-input directory through Applications or the original server command.
3. Select actual provider/environment/source identities and complete the existing review and native operation workflow.
4. Follow [RECEIVING.md](RECEIVING.md) to build the whole application, preserve the full private project and reopen it independently.

The public source projection retains complete implementation and third-party notices. Private outreach, case correspondence, host custody locators and completed private runtime receipts are excluded.
