# Fleet Availability Study Desk — first operating session

Open Fleet_Availability_Study_Desk.html. Under Study scope, open **Complete authored workflow** to see one full fictional depot shift before preparing real records.

The workflow includes four physical vehicles, 29 original and returned source families and 158 original documents. Fleet readiness & duties shows 2,880 eligible vehicle-minutes, including 720 unknown minutes. One vehicle completes repair, parts, supplier work, safety and operations release before its next duty. A second retains an open fault and cancelled assignment. A substitute completes the morning duty. The fourth retains unknown readiness.

For a real study, create a new study and name the measured operator and depot. Choose a completed consecutive window and actual source cutoff. Retain the originals and map the complete extracts in CSV intake & mapping. Use the 29 blank templates under templates/ for canonical columns; examples/input/ contains the fictional filled examples. Empty declared families still need a header-only extract.

Release review: create a complete case, identify each actual fault/work/parts/supplier/safety requirement, and record its original completion source in release_inputs. The editor can copy its exact current row binding. Record separate named safety and operations reviews against the same complete basis, then retain the actual readiness observation. Actual departures, completion and return stay separate source events.

Work measurement: retain every included physical member and all eight recurring phases for both methods. Measure active person-minutes independently from elapsed unavailable vehicle-time. Preserve incomplete or increased work; those observations help identify the real operating changes.

Save complete files during work. They retain original bytes, all unfinished forms, prior study editions and competing browser branches. Use Save & recover to export the readable report and complete study. A cold reopen restores the exact prior-study identity and its bound reviews.

The fictional course illustrates operating and receiving behavior. Apply the same source contract to the actual named operator and its existing authoritative systems.
