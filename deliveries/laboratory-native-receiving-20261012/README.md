# Complete Laboratory native receiving source

This package installs and runs the complete original Laboratory merchant/MCP customer workflow. It carries the original EQuIS 3 and EQuIS 4 deliveries, independent field decisions, cross-profile correspondence, the source for both native receiving families, and the original SF88 paid checkout and worker.

## Run the complete operation

Use the selected Linux worker's existing Node 24, Python 3.10+ and SDK directories. Run this one command through its maintained native capacity controller:

```bash
python3 receive.py \
  --directory /absolute/private/laboratory-native \
  --node /absolute/existing/node \
  --seller-dependencies /absolute/existing/seller/node_modules \
  --buyer-dependencies /absolute/existing/sf88/node_modules \
  --re2js /absolute/existing/node_modules/re2js
```

The command receives the full source with the original Commons reader, restores both exact original archives, binds the existing dependencies inside its owned source, imports the real merchant/scientific/customer modules, then transfers this same process to the merged `lab-edd-native-receiving.py` launcher. The original launcher owns the retained fixture, PTY, approval, SF36 ledger, checkout, merchant worker, cancellation, downloads and recovery.

Supply the same directory and dependencies to continue an interrupted operation. `--prepare-only` completes source and dependency receiving and returns the exact original command; the default runs the whole operation.

The original operation is **MCCAMPBELL-LAB-MCP-RECEIVING-9F77-20261012**, within **MCCAMPBELL-EDD-RECEIVING-9F77-20261012**. Keep its customer reference `mccampbell-lab-mcp:2026.10`, existing workspace, keys, job state and output files together during a host transfer.

## Source package receiving

The four unmodified Commons files in `host/` are the same maintained receiver used by the existing source operations. Their original repository and exact Git identities are recorded in `manifest.json`.

To receive the UTF-8 source independently:

```bash
node host/receive_source_carriers.cjs \
  --input source.json --manifest manifest.json \
  --out /absolute/owned/laboratory-source
```

The original reader verifies all selected files and reuses an identical existing member. The two binary ZIPs are retained separately in `originals.json`; the complete `receive.py` command installs both after source receiving.

The unchanged original `createSourceCarrierReader` has reconstructed this entire 371-file carrier in V8 with zero issues; every output text and byte hash matches its pinned original file. `source-reader-result.json` retains that actual package result. The native whole-operation command writes its own completion files on the accepting worker.
