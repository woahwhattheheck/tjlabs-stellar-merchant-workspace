This carrier preserves the exact active publisher and subsequent independent readback runners. The durable source and output coordinates are in operation.json. It complements the full retained input, prepared payloads, and ordinary archive parts already in Git.

## Continue the existing publication

Read the current output branch and its progress.json first. A final manifest.json plus receipt.json means publication has completed; continue with ordinary reopening. Otherwise confirm the current writer has stopped, then recover the same publication from its committed progress using the maintained publish-prepared-git.cjs README at the pinned publisher commit. Preserve the original part order, companion files, source index head, and exact metadata identity. Keep the existing assembled README.md and assemble-archive.mjs unchanged while resuming.

The frozen active implementation uses full original-member validation. Replaying a retained prefix performs the original validation but creates no duplicate blobs or commits. The newer packed-emission option is a separate explicit operation; it is not the active writer's implementation.

Fetch the exact source checkpoint at source.head/source.path and verify its complete bytes/SHA before reading its metadata/payload fragments. Source object paths resolve relative to the source checkpoint directory, pinned to that same source head. Every referenced fragment and joined value has its original byte length and SHA. All original and successor object files are present at this source head. Avoid retaining obsolete metadata fragments from prior checkpoint boundaries in an active object cache.

The supplied publisher runner accepts injected tools, result normalization, a CommonJS source-bank loader, the exact source index, original object reader and publication options. Its Git API adapter uses expected-head updates, never force. Hooks retain progress and interruption state; complete output is returned only after final publication.

## Reopen the final ordinary archive

Fetch manifest.json freshly at the final publisher commit, then use verify-complete-archive.cjs with the exact maintained ordinary-zip-range and streamed-archive-source modules at the pinned reader commit. The source callback fetches each original part by immutable Git blob and the adapter checks both original base64-text and decoded-byte identities. The range reader verifies every ordinary ZIP member and the original export inventory, and calculates the whole ZIP SHA during that same pass.

Recover expectedCheckpoint by joining and verifying only the source index's metadata reference. Payload bodies are unnecessary for readback. The runner compares every reopened member with that original metadata: name, bytes, SHA, CRC, compression method, compressed size and mode. It also checks the original edition/session identities and sequence, complete source count, requests, editions and retained branches. An interruption before the final return is a partial pass; resume or repeat the ordinary readback without publishing a completed result.

For native file receiving, the maintained read-streamed-archive.mjs command accepts the downloaded manifest and adjacent objects directory. The adjacent assemble-archive.mjs writes the complete ordinary ZIP after checking its original part and whole identities.
