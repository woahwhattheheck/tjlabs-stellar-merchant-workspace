# Original merchant tariff operation

Run the complete saved tariff and pricing journey on an existing Node.js 22 and Python 3 host.

This delivery accompanies the installed tariff product in [PR178](https://github.com/woahwhattheheck/tjlabs-stellar-merchant-workspace/pull/178) and the original feature in [PR2242](https://github.com/woahwhattheheck/public-commons-sprint-2026/pull/2242). Its source packet contains **179 complete original files (2249464 UTF-8 bytes)**, the original fixtures, and the two native modules. Each file carries its exact Git blob ID. The packet selects canonical commit `8f7194ee403bc202e91b6d8f8fdb95f46c394de9` and records the two direct host-file-helper imports applied by this delivery.

## Run the accepted operation

Copy this directory to the existing native host. Choose a new output directory under an existing private parent, then run:

```bash
python3 run-native.py \
  --packet original-source-packet.json \
  --directory /mnt/data/tariff-native/SCF-MERCHANT-TARIFFS-25FD-20261012 \
  --node node
```

The receiver validates every original file and program before materializing the source. It resolves the existing Node executable, starts one native programme, and retains its process identity, output, error stream and final status. The native operation uses the repository's unchanged illustrative seller, observations and commercial terms. It needs no dependency installation or external network request.

The original programme saves its input requests before changing the private workspace. It compares exact graduated and volume tariffs, saves and recovers the same selection, converts the chosen USD price using the entered asset valuation, and uses the original price decision and download writers. It then exercises the standalone HTTP client, original integrated workspace, complete pricing backup and restore, tariff portfolio receiving, and cold reopening.

The same programme continues through the original Merchant Pricing MCP owner, tool declaration, HTTP handler and typed clients. It executes all 17 tariff tools against the same saved operation, resumes complete retained downloads, and reopens the owner. The unchanged example has no release package or release store; its stage request retains the original native configuration response. The other operations continue using the fixture's saved pricing and tariff state.

## Receive the result

The complete private result is written to:

```text
/mnt/data/tariff-native/SCF-MERCHANT-TARIFFS-25FD-20261012/
```

`native/flow-result.json` combines the original pricing journey and MCP continuation. The receiver writes `native-receiving-result.json` and creates `Merchant_Tariffs_Original_Operation.zip`, retaining complete source, requests, saved workspace, downloaded files, process output and result. Its final stdout gives the ZIP path, byte count and SHA-256. A failed process retains its returned failure and complete partial workspace in that same archive.

Return the complete archive and actual result to the existing ASTRA-DU/TARIFF-RX operation, `SCF-MERCHANT-TARIFFS-25FD-20261012`, in its original Pricing thread. Continue an interrupted operation from its retained request and workspace.
