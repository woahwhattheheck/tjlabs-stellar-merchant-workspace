## Storage and recovery

Every page starts with its exact embedded state as a new independent copy. It never silently substitutes another active browser copy. Every save retains a complete proposed version and conditionally advances that copy's head in one IndexedDB transaction. If another writer changed the head, the foreign head remains and the proposed version is available in Recovery.
Page saves are serialized. An older save cannot clear the dirty flag for newer input. Source replacement and opening another copy first preserve the current complete work. Failed preservation leaves the active copy intact. **Download working file** and **Portable desk** work after quota/storage failure. **Save independent copy** recovers the complete current work when storage becomes available.
Strict UTF-8 decoding preserves BOM and CRLF. Untouched text is retained separately from normalized textarea display. An actual edit creates proposed text; previously admitted originals remain exact. Invalid mapping JSON and partial forms stay downloadable.
Browser data may be cleared by the browser or operating system. A complete downloaded working file or portable HTML is the handover. The proposed-save journal can grow with large repeated saves; retain downloads and use a dedicated browser profile for substantial source cohorts.
