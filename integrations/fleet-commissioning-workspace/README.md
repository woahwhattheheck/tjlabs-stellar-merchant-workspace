# Fleet Commissioning Workspace

Open [fleet-desk.html](fleet-desk.html) for the complete offline device commissioning comparison. See [OPERATE.md](OPERATE.md) for source intake, original/corrected example, finding reviews, independent saved work and complete handover.

The nine-family core retains exact original CSV editions and reconciles organization-scoped devices, public certificate metadata, dated lifecycle events, telemetry and explicit expectations. It performs no cloud or device commands. Native browser receiving uses the caller's existing pages and server.

Rebuild with `node build.mjs`. Source and all authored example data are included; no external packages are required. Read [OWNER_PRODUCT_INSTRUCTION.md](OWNER_PRODUCT_INSTRUCTION.md) for actual rendered receiving and zero-spend controls.
