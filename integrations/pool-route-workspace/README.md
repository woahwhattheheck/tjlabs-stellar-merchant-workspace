# Pool Route Workbench

A complete offline and native workspace for one declared pool-service day and an explicit subscription-count period. Nineteen original CSV families connect customer/pool/property identity, expected visits, dispatch revisions, actual technician work, versioned service records, literal readings, exact report members, recipient delivery evidence and independent customer money.

Open [Pool_Route_Worked_Example.html](Pool_Route_Worked_Example.html) for the complete authored seven-edition example, or [Pool_Route_Workbench.html](Pool_Route_Workbench.html) for a blank study. See [WORKBENCH.md](WORKBENCH.md), [DOMAIN_WORKFLOW.md](DOMAIN_WORKFLOW.md), [NATIVE_WORKFLOW.md](NATIVE_WORKFLOW.md) and [POOL_ROUTE_INTAKE_CONTRACT.json](POOL_ROUTE_INTAKE_CONTRACT.json).

## Working behavior

- Retain every complete original source edition, imported byte receipt and unfinished browser form.
- Compare source-declared route order and actual arrivals without inferring road distance or optimized routes.
- Preserve literal readings, source media and exact report memberships across later corrections.
- Keep delivery transport, acknowledgement and last-observed events independently visible.
- Count distinct eligible pools from supplied period/rates/status authority, separately from customer invoices and payment allocations.
- Append source-bound attributed reviews and preserve complete native/browser continuation.
- Save immutable browser proposals with an expected-head transaction; recover complete exported work when local storage is unavailable.

## Build and continue

Use Node.js 22 or later. Every destination directory must be new.

```sh
node build.mjs new-applications
node pool-route-native.mjs --workspace saved-workspace.json --out new-native-export
node pool-route-native.mjs --workspace saved-workspace.json --command receive-command.json --out new-receiving
node run-operating-course.mjs
node receiving/run-controller-course.mjs
```

The full native chapter includes receiving/review commands and its existing complete course. The authored source course covers 29 meaningful domain paths; the browser controller course exercises 23 receiving/recovery/review paths through explicit interfaces. Actual native/browser receiving follows the retained complete package and current owner-controlled instructions.

The supplied examples are authored records. Technical public-rule citations explain the supplied rate/count comparison; the workbench uses the actual source-defined values selected by its operator.
