# Research Installation through the installed Grant client

Use the existing host-declared Grant workspace and its original running application. This interface keeps the native Source Desk, Workshare selection, Installation writer and customer archive together. It does not create a second case database or infer rights, acceptance, payment terms or source authority.

## Retain complete original files

Select the complete native economic project, issued Research package and any explicit customer return. The native project limit is 480 MiB; issued packages and customer returns each allow 256 MiB. These are binary input limits. The merchant provider's ordinary request JSON remains 32 MiB, ordinary Source Desk files remain 8 MiB, and all existing case/plan limits retain their original behavior.

Configure one existing input alias with kind research-project, research-issued-package or research-customer-return. The host configuration owns the actual path and may pin its complete SHA256. Alternatively use the existing receive_begin/chunk/commit tools with the same explicit kind and full byte count/SHA, or a complete retained snapshot. The agent selects aliases or retained IDs, never arbitrary host paths. Preserve every original byte; summaries and extracted tables do not substitute for the source.

Call merchant_grant_research_installation_import with workspace, caseId, draftId, the original request UUID and actor, kind, plain original name, input reference, expectedInputSha256, sourceUrl and actual observedAt. The raw native upload is separate from the Source Desk revision. Its file ID is opaque research- followed by 64 hexadecimal characters; it identifies the whole upload intent and is not the original source SHA.

After a lost response, call research_installation_request with the same UUID and actor. COMPLETE returns its exact retained receipt. INPUT_RETAINED means all original bytes are already in native custody; call research_installation_resume without another source body. NOT_RECORDED requires the identical original upload selection and bytes. Preserve any inputIntentRetained flag and the original source URL/time. Never give an uncertain upload a new UUID.

## Review and save through the original writers

Use research_installation_inspect with both opaque fileId and expectedSha256. Its summary retains original definitions, capture identities, product/edition bindings, source URLs and native rights/review metadata. Full originals remain downloadable.

Use research_installation_template with the actual current case expectedVersion, selected sourceId/expectedSourceSha256, matching optional packetSourceId/expectedPacketSha256, original workshareCaseId and current installationId/expectedRevision. Null Installation with revision zero selects an explicit new installation. An existing Installation uses its actual current revision. The complete returned document preserves the original operating and commercial selections.

The native economic-research profile requires explicit source purpose, authority, redistribution and retention decisions. Save the complete reviewed selection with the existing merchant_grant_source_desk_command_prepare, action selection.save, then retain its returned complete operation before source_desk_execute. Use the same original mechanism for prepare and research.attach. Exact command receipts and original draft revision guard every write; source_desk_reconcile recovers an uncertain original request. Research attachment does not perform the separate native Installation Preview/Save. Review that full preview and save through the original Installation writer with its exact request and current case revision.

A received customer return remains original source. This Installation workflow does not adopt it into the economic product; the producer's native Research comparison and explicit apply remain authoritative.

## Download complete files and receiving archives

research_installation_file_describe requires opaque fileId and original expectedSha256. research_installation_file streams that exact full source into the existing private retained-file store and returns a snapshot/file_read reference.

After native Installation Save, call research_installation_archive_describe with caseId, draftId, preparationId, installationId and the exact saved revision. The native exporter freezes the complete archive once and returns its actual bytes/SHA256. Keep that descriptor. Call research_installation_archive with the same selection and returned expectedSha256. Later unrelated case changes cannot silently replace this selected archive.

The whole archive allowance is 2 GiB. Downloading uses bounded stream writes, complete-byte hashing, fsync and exclusive atomic publication; it never concatenates the whole archive into an agent response or Buffer. The existing retained file reader validates the original full file and delivers bounded chunks. Continue merchant_grant_file_read using the returned snapshotId, expectedSha256, offset and readId; use file_release when done. Reader IDs are process-local. After expiry or restart keep the same snapshot/SHA/offset and omit the old readId. The retained original file remains available.

A local retention failure is distinct from an uncertain native mutation. If a complete descriptor is returned with retention FAILED, retain its original selection and retry the same download after storage is available. Do not create a replacement native request or export identity.

The original native CLI handles full archive receiving into a separately selected workspace using installation-source-desk.py research-receive. RESEARCH_INSTALLATION.md documents its exact arguments and all original command variants. Complete source history, exact original files, the saved Installation, original Source Desk ledger and independent editable Research projects travel together. A received historical Source Desk request is available via research_installation_original_request; it is provenance, not permission to replay an old write into a new case.

## Typed client

The installed GrantWorkspaceClient exposes researchInstallation(action,input) for import/request/resume/inspect/template and descriptor reads. downloadResearchInstallationFile('file'|'archive',input,absoluteFilename) receives the complete binary to an existing private directory, verifies exact descriptor bytes and SHA, and publishes without overwriting a different original file. Both methods use the client's original authenticated connection and existing pending-request drain. Closing a borrowed client does not stop another owner's application.

All new public types are exported through the existing grant agent declaration and the grant/research-installation-agent export. No credentials appear in a tool response. Existing SourceDesk, Flowable, Econdb, DCAT, billing, forecasting and source-collection interfaces remain intact.
