# A2A merchant task workspace

Review a real A2A Agent Card and message, retain the native task plus every output file, freeze the reviewed result, and publish that exact complete edition with the original Starforge seller.

The full operator application includes source and task history, complete artifact custody, reviewed seller publications, original SF82 release staging/activation/rollback, named portable packages, fresh receiving and safe original-request recovery. It uses the official @a2a-js/sdk 1.3.0 for A2A 1.0 and the original Dataset writer lease for its local workspace.

Start the source CLI with `node cli.mjs workspace --workspace PRIVATE --connections HOST_JSON`, or use the installed `starforge a2a` command and managed Applications entry.
