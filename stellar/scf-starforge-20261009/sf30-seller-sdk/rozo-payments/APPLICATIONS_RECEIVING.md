## Continue a lost response or interrupted host

Run the same command with the same original directory and source binding. Progress retains exact request bodies before dispatch and preserves accepted result files before advancing its phase.

- Save reuses the original UUID and review ID. An earlier retained success plus a missing native application stops for original-store restoration.
- Start uses its original UUID, complete reviewed argv and resource selection. A prepared run without a dispatched worker resumes through the original Applications recovery API.
- An active original worker is reused. The programme never infers that an inaccessible process has stopped.
- A definitively drained listener can receive an explicitly recorded following start after its original worker lease is free. EXITED, LAUNCH_FAILED or reconciled terminated-process outcomes qualify only when no Stop was requested. Every earlier run and request stays in history. An unknown launch outcome or an explicit Stop requires the original operator reconciliation.
- The original working-export request is retained before its first POST. A lost response retries that same body; the native service checks its original fingerprint and returns or finishes the accepted delivery.
- Stop keeps the original application/run IDs. The programme waits for the same worker to drain before runtime receiving.
- An interrupted runtime preparation preserves its complete partial directory. The original `recoverRuntime` or runtime-transfer recovery composes a new target from those retained originals. A missing previously accepted READY runtime requires restoration.
- An existing complete receiving result is compared with the original selection and reused. It is never replaced with a fresh result merely because the caller lost its response.

The original Applications workspace is part of the operation. Restore its native state and history rather than replacing it with a new empty workspace. Progress or local request files that retain full exact bytes can restore missing redundant receipt copies; a missing authoritative native store is a different condition.
