# NetCDF workspace native contract

`python cli.py --workspace PATH invoke OP --json JSON` returns one complete JSON result. `rpc` starts one retained process: each input line is `{id,method,params}`; each output line is `{id,result}` or `{id,error:{code,message}}`. `create --title TITLE`, `serve --port 0 --receive-root PATH`, and `receive ARCHIVE --expected-sha SHA` are also native commands. `serve` prints `{schema:"stellar-forge.netcdf-startup.v1",state:"LISTENING",url,binding,instanceId,tokenFile}`. Browser session: POST `/api/session` `{token}`; /api/launch is public startup metadata only.

HTTP POST `/api/invoke` `{method,params}` returns the direct result. GET `/api/state` calls overview. POST `/api/sources?name=FILE&reference=SOURCE` streams an entire original binary to import and returns its source. GET `/api/object/SHA?name=NAME` downloads complete original bytes. POST `/api/receive?name=FILE&expected_sha=SHA` streams the complete original archive to the selected receiving root, returns `{directory,binding}`, and that received project can be independently opened with the original command. Receiving does not switch the sending session.

Native actions (parameters use snake case):

- `binding` → `{schema:"stellar-forge.netcdf-binding.v1",project_id,directory,sha256}`.
- `overview` → `{schema,project:{id,title,revision,created_at},sources,selections,runs,reviews}`. All lists are complete; source catalogs may be paged through variables.
- `import` `{path,name?,reference?,request_id?}` → source `{id,name,sha256,bytes,reference,imported_at,catalog:{format,attributes,groups,dimensions,variables}}`. Sources retain original immutable bytes. `sources` → `{items,total}`; `source` `{id}` → complete source.
- `variables` `{source_id,offset?,limit?,query?}` → `{items,total,next_offset}`. Each `{path,name,group,dtype,shape,dimensions:[{name,path,size,unlimited}],attributes,cf:{coordinates,grid_mapping,bounds,ancillary_variables,formula_terms,calendar,units,standard_name,axis},selectable}`. `variable` `{source_id,path}` → that descriptor.
- `preview` `{source_id,path,slices?,decode_cf?,offset?,limit?}` → `{variable,selection:{slices,shape,cells},items:[{index,raw,decoded?}],total,next_offset}`. Slice keys are the original dimension names or their absolute paths; values `{start,stop,step}`. Half-open bounds and positive steps only. Omitted dimensions select their complete length. Native raw values retain exact integer, string, bytes, compound, enum and variable-length identity; non-finite numbers and wide integers use explicit tagged JSON.
- `selection.save` `{title,source_id,variables:[{path,slices?}],decode_cf?,include_coordinates?,expected_revision?,request_id?}` → immutable saved selection `{id,title,source_id,source_sha256,variables,decode_cf,include_coordinates,created_at}`. Explicit index choices retain the original dimension identity. `selections` → `{items,total}`; `selection` `{id}` → complete selection.
- `run` `{selection_id,request_id?}` → immutable result `{id,title,selection_id,source_id,source_sha256,created_at,cells,variables,files:[{name,sha256,bytes,mime}],status:"complete"}`. Complete files are `selection.nc`, `values.jsonl`, `values.csv`, `manifest.json`, `report.html`. Coordinate/reference variables accompany the selection when requested and preserve original metadata. `runs` → `{items,total}`; `run.get` `{id}` → complete result.
- `review.save` `{run_id,decision,reviewer,notes,expected_revision?,request_id?}` → revisioned review `{id,run_id,decision,reviewer,notes,created_at}`; decisions `accepted`, `needs-work`, `observed`, `excluded`. `reviews` → `{items,total}`.
- `object.describe` `{sha256}` → `{sha256,bytes}`; `object.read` `{sha256,offset?,limit?}` → `{sha256,offset,total,base64,next_offset}`. Read through EOF and verify the entire returned digest.
- `report` `{run_id}` → the run's complete report file descriptor.
- `export` `{output?}` → complete private project ZIP descriptor `{name,sha256,bytes,mime,path?}`. Includes every original, selection, result file, review, request and the whole editable application source plus requirements. Excludes browser keys and caches. Default export becomes a retained object.
- `receive` `{path,destination,expected_sha}` → `{directory,binding}`. Hash/member-verified, create-only, repeats same completed archive safely. Independently editable source/history remain intact.

Results/errors never silently truncate a source population. UI displays names and readable dates by default, with native identities in optional details. `NETCDF_CONFLICT` retains expected-revision conflicts; `NETCDF_INVALID`, `NETCDF_MISSING`, `NETCDF_SOURCE_CHANGED`, `NETCDF_RECEIVE_CONFLICT` identify input/source/receiving failures.
