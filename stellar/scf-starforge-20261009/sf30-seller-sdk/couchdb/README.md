# Native CouchDB source and merchant

The complete installation, operator, field mapping, native publication, managed Applications, merchant tools, customer transfer and actual-engine receiving guide is [products/couchdb/README.md](../../../../products/couchdb/README.md).

The command entrypoints are:
- cli.mjs: native capture, inspection, exact source view and edition comparison.
- workspace-cli.mjs: the original authenticated workspace, saved actions/queries, complete file download and portable receiving.
- agent/cli.mjs: original merchant host setup, serving and source-owned tool calls.
- receive.mjs: one complete actual CouchDB-to-publisher-to-seller-to-customer-to-receiving operation.

Source ownership remains in the existing private operator. Core capture reads the selected native origin, raw pages and revision-pinned attachment bytes. publisher.mjs composes the original source-dataset publisher; deployment.mjs composes SF82's original dataset release; portable.mjs and archive.py compose the original source archive and existing SQLite/dataset/release lifetimes.

examples/connection.json and examples/queries.json are editable native input shapes. Supply the selected real source and its recorded review, then use the complete product guide.
