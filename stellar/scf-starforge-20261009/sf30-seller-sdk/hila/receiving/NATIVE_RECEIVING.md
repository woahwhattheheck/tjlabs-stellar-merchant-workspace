## Complete native sequence

The procedure retains and re-parses every original questionnaire byte, all four languages and the complete 11/10/10/10/5 item catalogue. It produces a 64-row CSV and a 72-row JSON source from literal original codes, with unique explicit synthetic record keys. Both are labelled synthetic-engineering in their complete edition provenance.

The controlled source includes declined/missing consent, no-new-information branches, explicit no-response, an absent and a null answer, one invalid answer, multi-country and overlapping role membership, an intentionally unmapped item and private free-text sentinels. The full originals remain available. Coded analytics and public reports must exclude the private fields.

Each immutable edition is saved through the original native build and complete request lookup. The driver reads every native coded row, retains the actual original Dataset query response and exports all three merchant dataset files per edition.

Four saved source reviews demonstrate:

1. Unconfigured methodology with full coded distributions and unavailable composite values.
2. An explicitly synthetic approved calculation/disclosure definition, named review and a complete older packet.
3. A selected country cohort, an explicit respondent exclusion and a named cell note.
4. Restored whole-edition comparison while preserving those review decisions.

Independent direct arithmetic over the controlled source checks actual consent, selected and information-gate denominators plus the scored respondent count and mean in every overall dimension. The first approved item assigns partial a null score deliberately, demonstrating an explicit missing score distinct from a missing response. All other synthetic scores and weights are complete declared inputs.

The procedure produces the whole private and approved aggregate report bundles, full offline HTML/CSV/JSON originals and the entire four-revision source packet. Original source models and Dataset children close before detached receiving starts.

The detached original workspace receives revision two, then the full revision-four packet, repeats that receiving, reconstructs every report and re-exports the original selected packet byte-identically. A separate fifth review is saved by the receiver. Receiving the older packet again returns its historical revision and preserves that later local revision. The receiver closes and cold-reopens with the same complete history and Dataset description.

## Same-operation continuation

The original per-output OS lease covers complete input retention, all model lifetimes and final publication. A second process cannot act on that output while its original owner holds the lease.

Each native save has a UUID derived from the original operation and action name. Its complete input is written before the native call. Reentry selects that same input and checks the original native request lookup; a committed save whose reply was lost returns its original result. Source ingestion is content-addressed and full acquisition replay is exact.

The initial full report-export descriptor is retained separately. A repeated archive export may report reused=true; continuation verifies the same file, bytes, hash, selection and revision while retaining the first full descriptor. Every actual later export observation is kept outside the already selected delivery membership. A predecessor source-complete record is accepted only when its full export identity agrees.

All report and archive publication uses the product's private stages, complete byte verification and original destination lease. Existing completed outputs must equal the original selection. The original deterministic full packet is reused; a second export cannot overwrite another workspace's completed destination.

A caught failure retains its full error and traceback under the same output directory. Close/drain occurs through the original workspace lifetime. After the actual process is known to have ended, invoke the same input and source operation. Completed native requests, archives and source rows are reused. A completed result is returned only after all selected files match its exact byte/SHA manifest. No new request ID or replacement source edition is introduced to bypass an existing result.

Browser/Applications receiving is a separate sequential stage on the same closed model state. A working native core result does not itself claim a READY installation or completed browser interaction.
