# SensorThings commissioning workspace

Receive a retained CSV or SensorThings source, review its entities and relationships, and commission one selected FROST service through the original FROST-Python-Client. The application extends the canonical SensorThings Desk with source intake, mapping, immutable plans, native jobs, verification, correction, compensation, map review and complete receiving.

The operating application, CLI, original-client installer and reference receiving programme are provided together. The native client is Fraunhofer IOSB's FROST-Python-Client 1.1.53 at commit `9f41f7794725fced63fcb07e6b33dbc1f897f2bc`. The original client source and LGPL notice are retained in the runtime capsule. STAM and Leaflet remain separately identified original browser dependencies.

The source-to-target plan is reviewed before the first native write. Original sources and actual HTTP/native receipts remain distinct from operator mappings and editorial corrections. An uncertain target effect waits for a recorded decision; it is not automatically repeated.

The complete handoff retains all source editions, mappings, plans, reviews, native attempts and source-backed target bindings, plus the editable operating source and browser asset identities. A receiving host can inspect the retained project without a FROST environment. Continuing target work requires that host's explicit target and runtime binding.

## Reference selection and status

The receiving programme uses the original 28-response Hamburg source recording and its 660 categorical observations. It writes only to the selected private FROST reference service. Hamburg's public service remains original read-only source custody.

A published programme is not a completed native result. Its actual completion is recorded only in the operation's final `delivery/CUSTOMER_RESULT.json`, after all sixteen phases, full archive checks, browser work and both closed workspace reopen operations complete. The original source limitations remain in that result: connector HTTP metadata and provider snapshot authority were not established by the retained recording.

Use the original source commit and complete source manifest in each receiving operation. Preserve the same private operation directory on interruption.
