## Current tool contract

| Tool | Complete input and outcome |
| --- | --- |
| response_status | Paged records or workshares, actual native workspace, hosted URL with trailing slash, counts and exact next offset. |
| response_inspect | Host input alias, exact full-file SHA256, prepare/compare/apply operation and original command where applicable. Returns original file identity without mutation. |
| response_prepare | Host alias plus SHA256 and command ID for the full native preparation request. Exact command replay reopens the original result before live revision admission. |
| response_record | Original record ID and optional explicit historical revision. Returns saved metadata, binding, workshare and attachment metadata. |
| response_export | Record ID, explicit record revision, current expected workspace revision and document/transfer/editor/markdown format. Freezes the exact original edition before asynchronous receiving. |
| response_compare | Host alias, exact complete-file SHA256 and current expected workspace revision. Its file is exactly recordId plus the full returned transfer. Preserves complete comparison in a publication. |
| response_apply | Host alias plus SHA256 and original command ID for the full native apply request, including explicit choices, named reviewer and any applicable changed-context acknowledgement. Exact original replay is preserved. |

Every publication selects workspaceId, recordId, recordRevision, editionSha256 and evidenceSha256. A comparison additionally retains its original input SHA256, incoming transfer digest, review digest and context digest. Its sourceRevision is the expected workspace revision. Publication retention itself advances that workspace revision. A new apply request therefore starts from the following actual status; an original replay keeps its old complete request unchanged.
