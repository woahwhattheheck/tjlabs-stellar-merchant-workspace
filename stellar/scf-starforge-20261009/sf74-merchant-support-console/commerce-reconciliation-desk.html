Commerce integration receiving

Compare one selected commerce export with its downstream CRM or ERP export. Keep exact amounts, duplicate keys, scope limitations and reviewer decisions visible.

This page runs locally. It makes no account, order, payment or customer identity changes. Its initial example is authored receiving data. Working copies keep unfinished local work and complete downloads; the validated input and review remain the receiving records. The existing Merchant Support case remains the persistent work record.

Working copies

A working copy keeps the complete input text, including unfinished JSON, the last analyzed source and recorded review, and every current review field. It is separate from the validated input and review files used by the original receiving commands.

Saved local window copies

Each window owns a separate copy. Reloading reopens its last committed copy into a new window copy. Opening a saved copy or file first downloads the preceding work; other copies remain unchanged.
