# HILA selected operator installation

Use the original distribution source-selection builder with selections/hila-operator.json. The recipe includes the complete HILA product, XML SourceFormat/Workspace and SF30 Dataset import closure, source-owned HILA contribution/provider, original runtime Applications assets, Python runtime component and SF46 installer.

Prepare and package through distribution/build.mjs and the maintained SOURCE_SELECTIONS.md interface. Install the original archive with its complete archive/profile/lock receipts. Inspect the resulting runtime and require READY before application review. Keep the original archive unchanged.

The installed command is dataset-hila. Initialize or receive the private HILA workspace with that command. In Applications select HILA round review, its original workspace directory and the existing Python 3.11+ executable. The managed review reads the entire 22-file source/binding selection, original workspace marker/SQLite identity and Python environment before the existing controller saves and starts the application.

Startup retains its original JSON announcement and reads back /api/launch with the exact capability. It must select the reviewed workspace, source release, Python executable, binding SHA and process identity. The source-owned observer performs those checks.

Use the original Applications Stop and existing recovery path. A second process cannot open the same native workspace while its current operator owns the OS lease. Source imports, report downloads and receiving run on that same workspace.

The complete README.md and METHODOLOGY.md are part of the product. Questionnaire/response data are supplied separately with original permissions; no respondent dataset or full third-party questionnaire is embedded in this source recipe.

Requirements are the original Node 22+ Dataset runtime, Python 3.11+ and existing local browser. There is no third-party Python package dependency. The optional Node download helper uses the original Linux flock state lease.
