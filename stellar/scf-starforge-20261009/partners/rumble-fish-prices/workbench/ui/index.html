Interpret the original fields

as_of
The time of the price observation; the configured age threshold applies here.
updated_at
When the snapshot row refreshed. A refreshed row can still carry an older price.
price_status
priced, carried or unpriced; a temporarily empty status stays unknown.
volume_24h_usd
The provider's total trade volume across both sides of pairs. Per-venue source volumes need not add to this total.
null OHLC values
Retain null and the reported trade/activity counts. Collection does not fill a missing market price.
