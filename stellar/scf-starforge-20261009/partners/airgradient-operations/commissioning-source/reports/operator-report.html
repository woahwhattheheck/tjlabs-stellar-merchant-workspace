Read the coverage correctly

  • Coverage counts valid values for each requested measure. A returned hour with a null PM10 value is not a reported PM10 measurement.
  • Missing bucket hours, explicit nulls, absent fields and invalid values remain separate. Valid zero values are included.
  • Outdoor history requested PM2.5 only. Other outdoor fields in CSV are labelled NOT_REQUESTED, even when the separate current snapshot contains them.
  • Means use available provider hourly aggregates with equal weight. No interpolation, health classification, extra correction or unit conversion is applied.
  • Indoor names and addresses are not inferred from coarse public coordinates. Candidate pages do not represent the full global sensor population.
