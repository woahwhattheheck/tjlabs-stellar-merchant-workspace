## Open the full operator

Use Linux, Python 3.12 or later and Node.js 22.16 or later. The selected operator
uses Node's built-in modules and has zero npm runtime dependencies. Allow memory
for the complete 258.8 MB native workspace; the launcher gives Node a 4 GiB heap.

From this extracted handover folder:

```sh
python3 START_HERE.py --directory /absolute/private/osf-operator --serve
```

If Node is outside PATH, add `--node /absolute/path/to/node`.

The launcher verifies the exact selected SDK and complete original workspace,
extracts the unchanged source package, and uses its original native receiver.
It then starts the shared Research application with the original Zotero bridge.
The current private browser connection is saved in
`/absolute/private/osf-operator/operator-connection.json`. Open its `url` value
locally. In the Research navigation, **Zotero library** opens the complete
catalogue, collection project and original handoff.

Run the same command with the same directory to continue this exact receiving
operation. Each independent receiving operator gets its own new directory.
Stop the foreground operator with Ctrl-C; its owned child closes normally.
