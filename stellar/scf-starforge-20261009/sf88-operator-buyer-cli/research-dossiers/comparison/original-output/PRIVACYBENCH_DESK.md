## Size and format admission

The supported profile is the documented native result schema at TonicAI/privacy_bench_metrics commit 5dfcaf57f0dae69b77d819ef04558944d31015de. The producing evaluator version entered in the record remains the actual version used for that result.

The original results JSON is limited to 32 MiB. All selected and generated files together must fit 63 MiB. The complete encoded Research run must fit 64 MiB. There may be up to 10,000 projected metric rows and 190 original supporting files. Base64 and generated review/CSV content count toward the final envelope. Admission is checked before a candidate or run request is frozen.

Use a complete smaller original cohort or producer output when it exceeds these limits. Truncating a file, discarding source rows or dropping producer sections changes the scientific source and is not an intake remedy. Duplicate JSON object keys are rejected, including escaped-equivalent names.
