## Continue after interruption

The create-only selection.json binds the operation, actual source commit/root,
listener origin, all selected source hashes and the film/print choices.
A different selection cannot overwrite it.

A completed retry verifies every retained artifact and returns the original
result without repeating the browser journey. An interrupted attempt stays
under its original directory, including completed outputs and INCOMPLETE.json
when the host could write it. Reopen the same original listener and Page with
the same selected source and arguments, then call this continuation.
Only the read-only visual journey repeats. No source build, purchase, provider
request, numerical model or grant submission is replayed.

The function does not acquire or recover a host/browser lease. The original
owner resolves its actual stopped/live state before invoking it once on its
owned Page. Do not run concurrent copies against the same Page or directory.

If remote film metadata cannot load, retain the incomplete result and actual
failure. The owner can explicitly choose readPublishedFilm: false in a
**different** receiving output directory for an offline local review. That
result labels the film as source-links-only, without claiming playback.
Likewise, printPdf: false preserves the ordinary browser's print route without
claiming a generated PDF. Keep these distinctions in the handover.
