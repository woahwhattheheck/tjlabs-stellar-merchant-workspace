## Merchant invoices, paid fulfillment and portable operating projects

The merchant workspace gives an operator a complete path from a priced service request to a retained payment record, delivered file and reopened operating project. It is useful when a merchant sells a report, data extract or another completed resource, and when an implementation partner must hand the running service to the customer's operator. The invoice, payment request, authorization, settlement observation, delivery edition and result remain attached to the same business record.

This is an implemented operating foundation for the existing Stellar Forge programme. Its completed commissioning used five local x402api protocol fixtures, including Base USDC and Solana payment-term vectors. Those fixtures exercised the actual application, HTTP, SQLite and cryptographic verification code; they did not submit real payments. The grant's separate development baseline remains **18 actual Stellar purchases and 0.0411 XLM**. The five local invoices do not change that baseline or the independent merchant and buyer targets.
