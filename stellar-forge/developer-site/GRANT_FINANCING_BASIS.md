# Grant financing basis and commercial delivery assumptions

This explanation makes the current grant and commercial-capacity figures readable with their complete calculation inputs. The requested programme remains **USD 38,000 for 400 prospective hours over 150 days**. Five separately proposed customer workshares provide a conditional commercial comparison. Their original price, included work, review and payment terms remain the basis for agreement and delivery.

The [complete financing inputs](./grant-sources/financing-basis.json) carry all eight selected alternatives, all original phase dates and costs, all customer milestone dates and amounts, and the results of all 27 dated cash curves. The [calculation module](./grant-sources/financing-basis.mjs) reproduces those curves from the retained schedule using exact integer cents. Readers can inspect every amount here and reproduce the detailed figures without access to private correspondence.

## 5. Reproduce and use the calculation

The companion JSON contains every selected phase date and cost, original milestone date and value, the complete six-package grant allocation, the five original phase/hour plans, all eight resource alternatives and all 27 expected cash summaries. The calculation module consumes those retained dates. The original allocator remains responsible for choosing or changing a schedule.

From the repository root, run:

~~~sh
node --input-type=module -e '
import fs from "node:fs";
import { calculateFinancingBasis } from "./stellar-forge/developer-site/grant-sources/financing-basis.mjs";
const data = JSON.parse(fs.readFileSync("./stellar-forge/developer-site/grant-sources/financing-basis.json", "utf8"));
console.log(JSON.stringify(calculateFinancingBasis(data), null, 2));
'
~~~

The module reconstructs **27 curves across 6,353 daily rows**, checks each retained cash summary and the full labor totals, then reports the original and reserve-adjusted contribution. It uses integer cents and cumulative half-up rounding, matching the original phase-cost convention. This source was executed against the complete retained dataset before publication.

The source basis records the original input and result Git identities, the original allocator identity and its actual recorded execution method. The October 12 study was calculated in V8 from a fixed-point translation of the maintained allocator and supplied its native Python continuation. This publication reopens that complete calculation and reproduces its financial projections from the saved phase schedule.

To continue delivery, open the existing operating case, select the complete alternative, record actual customer triggers and named availability, enter the selected reserve's actual cash date, and save the revised Forecast and Portfolio alongside their earlier editions. The same case retains customer terms, cost assumptions, actual obligations and receiving history.
